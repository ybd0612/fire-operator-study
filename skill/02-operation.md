# 2. 设施操作

设施操作是中级工两个方向共同的重要考核内容。实操要遵循“确认对象—选择方式—执行操作—观察反馈—恢复状态—记录报告”。

## 一、火灾自动报警系统

掌握控制器开关机、主备电切换观察、火警/故障信息查询、消音、复位、屏蔽与解除屏蔽、手动/自动状态识别和联动控制盘操作。操作前确认模拟场景和影响范围，操作后核对指示、反馈和系统状态。

## 二、消防泵组

- 识别消防水泵、稳压泵、控制柜、启泵按钮、压力表、阀门和水泵接合器。
- 掌握自动、手动、远程/就地控制方式及主备泵切换逻辑。
- 启泵前确认电源、阀门、管网和无异常；启泵后观察运行电流、压力、振动、声音和反馈信号。
- 停泵、复位、恢复自动状态必须按设备规程执行，严禁在无确认时随意关闭阀门或切断电源。

## 三、防排烟系统

识别送风机、排烟风机、风阀、排烟口、送风口和控制柜；掌握手动启动、联动反馈、停止和复位。确认风机方向、风阀开闭、反馈信号与现场状态一致。

## 四、应急广播与消防电话

掌握分区选择、音量/话筒使用、广播启动与停止、消防电话分机呼叫和主机接听。操作后确认目标区域有声、通话清晰，并避免把普通广播与消防应急广播混淆。

## 五、防火卷帘与电梯迫降

- 防火卷帘：识别上升、下降、停止、限位和反馈；操作前清空下方区域，下降后确认位置和反馈。
- 电梯迫降：按预案和授权操作，确认迫降信号、消防员电梯/普通电梯状态及反馈；不得把迫降操作当作日常随意试验。

## 六、评分要点与易错点

1. 口述或确认安全条件；
2. 选对设备、方式和区域；
3. 按顺序操作，不能漏步骤；
4. 观察反馈并说明结果；
5. 恢复规定状态并记录。

常见失分：未确认自动/手动状态、泵启动后不看压力反馈、风机启动后不核对反馈、卷帘下降区域有人、操作结束忘记恢复系统状态。
