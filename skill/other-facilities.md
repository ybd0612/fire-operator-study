# 其他消防设施项目卡

> **适用方向：消防设施检测维修保养（四级/中级工）**。本页围绕 2019 年版国家职业技能标准中设施操作、保养、维修、检测的“其他消防设施”内容学习。答案用于建立判断框架，不替代鉴定站现场评分表、设计文件、设备说明书、检测方案和专业作业许可。

## 1. 学习目标

读完本页后，应能按同一条主线学习每类设备：

```text
识别对象 → 确认安全 → 执行操作/检测 → 观察动作与反馈 → 判断异常 → 恢复状态 → 记录结果
```

重点掌握：

- 防烟排烟系统的风机、风阀、排烟口/送风口及反馈；
- 防火门、防火卷帘、防火阀的分隔作用与动作确认；
- 应急照明、疏散指示、消防电话和应急广播；
- 消防电梯迫降的接口和专业协同边界；
- 灭火器与室内消火栓组件的检查、维修和检测边界。

## 2. 先建立一张设备地图

| 设备 | 主要作用 | 检查时要证明什么 |
| --- | --- | --- |
| 送风机、送风阀/口 | 为防烟区域提供加压送风 | 风机运行、阀口到位、控制室收到反馈 |
| 排烟风机、排烟阀/口 | 排出烟气或形成排烟通路 | 风机运行、阀口动作、反馈和设计区域对应 |
| 排烟防火阀 | 按设计工况阻断火烟传播 | 动作、复位、位置反馈和本体完好 |
| 防火门/卷帘 | 形成防火分隔 | 关闭或下降到位、无阻挡、状态反馈正常 |
| 应急照明/疏散指示 | 断电或联动时提供疏散照明和方向 | 应急转换、点亮、方向、故障监视和恢复 |
| 消防电话/应急广播 | 组织指挥和传递疏散信息 | 通话清晰、分区广播和强制切换有效 |
| 消防电梯 | 火灾时按设计要求迫降并供消防使用 | 输入、迫降层、门状态和反馈，不擅改电梯安全逻辑 |
| 灭火器/消火栓 | 供人员处置初起火灾 | 类型、位置、组件和有效性，不把外观完好当成系统合格 |

## 3. 防烟排烟系统

### 3.1 组成与原理

系统通常包括机械加压送风机、排烟风机、风管、送风阀/送风口、排烟阀/排烟口、排烟防火阀、挡烟垂壁、控制柜、联动线路和反馈装置。具体配置以设计文件和竣工图为准。

理解信号链：

```text
火灾信号/手动指令
→ 控制器或控制柜发出启动命令
→ 相关风阀/排烟口动作
→ 风机运行
→ 运行、阀位或故障反馈返回
→ 控制室核对区域和状态
```

> **注意：** 不能把“风机转动”直接等同于“排烟系统合格”。还要核对阀门位置、区域对应、运行状态、反馈以及方案要求的风量/风压等数据。

### 3.2 操作与检测卡

1. 核对区域、设备编号、设计逻辑和测试方案；
2. 通知控制室、相关楼层和可能受影响人员，采取防误动作措施；
3. 确认设备处于准工作状态，风机检修时执行断电、挂牌和监护；
4. 按方案分别执行手动启动、自动联动或阀门动作测试；
5. 观察风机启停、旋转和声音振动，核对阀门是否到位；
6. 在控制室核对启动、运行、故障、阀位等反馈；
7. 按方案恢复阀门、风机、控制柜和联动状态，确认无遗留故障；
8. 记录区域、方式、动作、反馈、异常、测量数据和复测结果。

### 3.3 保养、维修与异常

- 保养：清洁风机、控制柜、阀口和执行机构，检查固定件、端子、线路、皮带/轴承和障碍物；
- 维修：风机、电机、执行器、限位、易熔片或反馈部件按产品文件和资质边界处理；
- 异常：风机不启动、阀门卡涩、反馈不一致、异响振动、风量/风压异常、联动区域错误；
- 不能通过拆线、拔模块、长期屏蔽或擅改逻辑“消除”故障；
- GB 51251-2017 的维护条款可用于建立周期意识；本轮公开目录核对显示该标准当前标注为现行，具体检测项目和判定仍必须核对标准全文、设计文件及项目方案。

## 4. 防火门、防火卷帘和防火阀

### 4.0 先分清三类设备在“防什么”

这三类设备都可能出现在建筑分隔位置，但不能当成同一种东西：

| 设备 | 装在哪里 | 主要限制什么 | 零基础识别方法 |
| --- | --- | --- | --- |
| 防火门 | 人员或设备通行的门洞 | 关闭后形成门洞处的防火分隔 | 看门扇、门框、合页、闭门器和门上标识 |
| 防火卷帘 | 较大洞口或需要升降分隔的位置 | 帘面下降后封闭洞口，阻止火焰和烟气直接穿越 | 看帘板、两侧导轨、上部卷轴和电机 |
| 防火阀 | 风管穿越防火分隔处 | 在规定条件下关闭风道，避免火烟通过风管扩散 | 看风管上的阀体、执行机构、释放部件和位置反馈 |

记忆方法是：**人走的洞口看门，较大洞口看卷帘，空气走的通道看阀**。判断一个设备是否正常，不能只看“有没有这件东西”，还要看它能否在需要时关闭、关闭后是否到位、控制器是否收到对应反馈，以及测试后能否恢复规定状态。

### 4.1 防火门

防火门学习四件事：门体完整、闭门可靠、顺序正确、状态可反馈。

检查内容：

- 门扇、门框、合页、闭门器、密封件和铭牌完好；
- 常闭门不应被楔住、插销固定或堆物阻挡；
- 双扇门关闭顺序符合产品和设计要求；
- 常开门的释放器、门磁/状态开关和监控器状态正常；
- 联动释放后应按设计关闭，控制器显示与现场状态一致。

维修时不得随意打孔、加装普通插销或使用不兼容部件。门体耐火完整性受损时，不能用普通五金件替代专业维修。

### 4.2 防火卷帘

组成包括帘板、导轨、卷轴、电机、控制器、限位、手动装置、联动输入/输出和反馈。

操作和检测：

1. 清理下方和两侧区域，确认无人员、车辆和障碍物；
2. 核对手动、自动、联动测试条件；
3. 观察上升、下降、停止、限位和反馈；
4. 发现卡阻、下滑、异响或不能限位时停止反复操作，隔离区域并报修；
5. 测试后恢复控制方式、位置和故障状态，完成复测记录。

> **安全红线：** 卷帘动作区域严禁站人；不得用拆线或屏蔽代替维修，不得把帘板损坏简单当作控制器故障。

### 4.3 防火阀

防火阀应关注阀体、执行机构、释放部件、位置和反馈。检查开启/关闭动作、复位灵活性、风道障碍和反馈一致性；具体动作条件和维护周期以适用标准、设计文件、产品说明书和检测方案为准。

## 5. 应急照明和疏散指示

### 5.0 先分清“照明”和“指示”

应急照明和疏散指示都服务于断电或火灾等紧急情况下的人员疏散，但解决的问题不同：

- **应急照明**：解决“看不看得见”的问题，帮助人员看清地面、楼梯、通道和障碍物；
- **疏散指示**：解决“往哪里走”的问题，通过方向、出口或楼层信息帮助人员选择疏散路线。

所以，灯具点亮只能说明某个发光部件有光，不能证明方向正确、整条疏散路线连续、备用电源和故障监视都正常。检测时应把“能照明”和“能引导”分开核对。

### 5.1 系统组成

常见组成包括消防应急照明控制器、集中电源或应急照明配电箱、应急灯具、疏散指示标志、蓄电池、通信和配电线路。系统类型不同，控制方式和接线方式也不同。

### 5.2 学习与检测闭环

- 看控制器、集中电源/配电箱是否有故障；
- 看灯具安装、方向、标志面和遮挡情况；
- 按方案测试主电失电、联动或手动应急转换；
- 观察灯具点亮、疏散方向和故障反馈；
- 恢复主电，确认充电、常态显示和无新增故障；
- 记录系统类型、设备编号、转换方式、现象、依据和复测结果。

不得把普通照明、插座或其他负载接入应急照明系统输出回路；不得擅自改变疏散方向或以普通灯具替代消防应急灯具。照度、转换时间和持续时间必须引用适用标准、设计文件和检测方案，不能凭记忆填写。

## 6. 消防电话和应急广播

### 6.0 先分清“电话”和“广播”解决什么问题

- **消防电话**是双向沟通：一方呼叫，另一方接听并讲话，重点是通话链路和清晰度；
- **应急广播**是单向或按设计分区播报：控制端选择区域并发送声音，重点是分区、优先级、播报清晰度和强制切换。

因此，“电话能听见”不能证明广播分区正常；“某个扬声器有声”也不能证明整套广播系统正常。学习时先判断是在验证双向沟通，还是验证分区播报。

### 6.1 消防电话

组成通常包括消防电话总机、分机/插孔、线路和备用电源。检测时应核对总机与分机/插孔的呼叫、接听、通话清晰度、指示和故障监视。

故障排查顺序：

```text
确认对象和区域 → 查线路/端接 → 查总机/分机状态 → 分段测试 → 更换兼容部件 → 逐点复验
```

不得把普通电话系统或不明线路替代消防电话专线。记录通话双方、区域、结果、杂音/断续现象和复测结果。

### 6.2 应急广播

组成通常包括广播控制设备、功放、分区选择、扬声器、线路和备用电源。重点检测：

- 主机和功放无故障；
- 分区选择与现场区域对应；
- 火灾联动时强制切换逻辑符合设计；
- 播报清晰，扬声器和线路无明显断路；
- 测试后恢复正常广播/监视状态。

无声或断续时按“分区—功放—线路—扬声器”分段排查，不用不明负载替代扬声器。

## 7. 消防电梯迫降

### 7.0 先理解“迫降”是什么意思

“迫降”不是让电梯自由下落，而是火灾联动或授权测试条件下，由电梯控制系统执行预定的返回/停靠逻辑，使电梯退出普通乘客运行状态，转入设计规定的消防使用状态。具体返回层、门状态和控制权限必须按设计文件、电梯产品文件和专业维保方案确认，不能凭经验自行推断。

消防电梯迫降涉及火灾报警/联动控制器、输入输出模块、电梯控制接口、消防电梯控制系统和反馈信号。学习重点不是修改电梯程序，而是核对：

```text
迫降输入 → 电梯动作 → 到达指定层 → 门状态/运行反馈 → 控制室显示
```

测试前必须联系电梯维保单位，确认轿厢和井道安全，设置警戒并避免影响正常使用。不得短接安全回路、强行改写程序或由非专业人员拆修电梯控制系统。异常时记录电梯编号、触发方式、迫降层、门状态、反馈和维保单位处理结果。

## 8. 灭火器与室内消火栓组件

### 8.1 灭火器

检查：类型是否适配、数量和位置是否符合配置、筒体有无严重锈蚀/变形/泄漏、保险销和铅封是否完好、喷管和器头是否完整、压力指示是否处于产品规定状态、维修/报废标识是否清楚。

失压、泄漏、严重腐蚀、使用后或达到维修/报废条件的灭火器，应送有资质单位处理。不得自行充装或混用灭火剂。灭火器只适用于人员安全且火势可控的初起火灾，先报警、疏散并选择相容灭火剂。

### 8.2 室内消火栓

组件通常包括箱体、栓阀、水带、水枪、接口、软管卷盘和启泵按钮（如设）。检查箱门和标志、组件齐全、栓阀启闭、接口密封、水带状态、按钮报警和泵反馈。

放水测试前要核对方案、排水路径和防淹措施；测试后恢复阀门、控制柜、报警状态和记录。不得锁闭、遮挡、挪作他用或长期折压水带。水带、水枪、栓阀和按钮损坏时按同规格消防产品更换并复验。

## 9. 通用故障与恢复卡

| 现象 | 优先核对 | 不能直接做的事 |
| --- | --- | --- |
| 风机不启动 | 电源、控制方式、保护、联动输入、反馈线路 | 反复强启或拆线屏蔽 |
| 风阀不到位 | 障碍、执行器、限位、供电、反馈 | 强行扳动带电机构 |
| 卷帘卡阻 | 导轨、帘面、限位、电机和区域安全 | 在下方站人或反复下降 |
| 应急灯不亮 | 主备电、集中电源、线路、灯具故障 | 接普通电源临时替代 |
| 广播无声 | 分区、功放、线路、扬声器 | 接入不明负载 |
| 电话不通 | 总机、分机/插孔、线路端接 | 改接普通电话线 |
| 电梯不迫降 | 输入、接口、反馈、维保状态 | 短接安全回路 |
| 消火栓无水/无反馈 | 阀门、水源、泵组、按钮、排水和联动 | 随意关阀、拆线或大流量放水 |

每个异常都必须形成：

```text
发现时间 → 现象与影响范围 → 临时防护/上报 → 授权维修 → 复测 → 恢复自动/联动/监视 → 复核记录
```

## 10. 分设备检测与故障诊断卡

### 10.1 检测闭环的统一写法

每类设施都按“对象与适用差异—前置安全—检测方法—动作反馈—恢复—记录”展开。检测时要区分：

- **命令已发出**：控制器、控制柜或现场按钮显示已输出；
- **现场已动作**：风机、阀门、门、卷帘、灯具、电话或广播出现实际变化；
- **状态已反馈**：控制室或设备端返回运行、到位、故障或通话/播报结果；
- **功能已恢复**：测试结束后恢复设计要求的自动、联动、监视、供电、阀位和环境状态。

以上四层不能相互替代。任何具体动作条件、照度、持续时间、风量风压、测量允许误差和产品维修条件，都应引用现行适用标准、设计文件、设备说明书和检测方案。

### 10.2 七类其他设施零基础学习卡

下面按“作用—组成—工作—正常证据—异常—恢复记录”学习。先分清设备解决的问题，再判断它是否完成了命令、现场动作和反馈闭环。

#### A. 防烟排烟设施

- **作用**：加压送风帮助防烟区域保持设计条件，排烟设施把烟气导出或形成排烟通路；二者服务区域和动作逻辑不同。
- **组成**：风机、风管、风阀/风口、控制柜、执行器、反馈模块和联动线路，具体以设计文件为准。
- **工作**：火灾信号或手动指令经控制器输出，阀门和风机按逻辑动作，运行/阀位/故障状态返回控制室。
- **正常证据**：区域对应正确，风机实际运行，阀口到位，反馈与现场一致，测量数据有测点、仪器和依据。
- **异常与恢复**：风机不转、阀不到位或无反馈时先区分供电、机械、控制和线路层；不得反复强启、拆线或屏蔽，测试后恢复自动/联动/监视。

#### B. 防火门、防火卷帘和防火阀

- **作用**：防火门关闭门洞，卷帘封闭较大洞口，防火阀阻断风管中的火烟传播。
- **组成**：门扇/门框/闭门器/释放器；帘板/导轨/卷轴/电机/限位；阀体/执行器/释放部件/位置反馈。
- **工作**：常闭门保持关闭，常开门在释放后关闭；卷帘按控制逻辑升降并到位；防火阀按规定条件关闭并反馈。
- **正常证据**：本体完整、无阻挡，动作方向正确、关闭或到位，状态反馈与现场一致，复位后无故障。
- **异常与恢复**：门不闭、卷帘卡阻、阀位不一致时先清场和保护分隔，禁止楔住、站在卷帘下、强扳带电机构或拆线；维修后按方案复测并恢复规定状态。

#### C. 应急照明与疏散指示

- **作用**：应急照明解决“看得见”，疏散指示解决“往哪里走”，不能用一盏灯点亮证明整套系统正常。
- **组成**：控制器、集中电源/配电箱、灯具、指示标志、蓄电池、通信和配电线路。
- **工作**：主电异常或联动条件满足时切换至应急状态，灯具点亮并按设计显示方向；故障信息返回控制器或集中电源。
- **正常证据**：转换方式符合方案，灯具点亮，方向连续正确，主备电和故障监视正常，恢复主电后回到常态。
- **异常与恢复**：灯不亮、方向错误或集中电源有故障时区分供电、通信、灯具和配置问题，不接普通电源替代；复测后确认充电、常态显示和无新增故障。

#### D. 消防电话与应急广播

- **作用**：消防电话验证双向通话，广播验证分区播报、优先级和强制切换；一个有声不能代替另一个功能。
- **组成**：电话总机、分机/插孔、专用线路和备用电源；广播主机、功放、分区选择、扬声器、线路和备用电源。
- **工作**：电话建立呼叫与接听链路；广播从控制端选择区域并发送声音，按设计要求切换或优先播报。
- **正常证据**：电话双方清晰通话，广播分区准确、播报清晰、故障监视正常，测试后恢复常态模式。
- **异常与恢复**：单点不通优先查点位和局部线路，多点异常再查主机/电源/干线；不得改接普通电话、接入不明负载或用单个扬声器结果外推全区。

#### E. 消防电梯迫降

- **作用**：在火灾联动或授权测试条件下，使电梯退出普通乘客运行状态并执行设计规定的返回/停靠逻辑，不是自由下落。
- **组成**：报警/联动控制器、输入输出模块、电梯接口、电梯控制系统及迫降层、门状态和运行反馈。
- **工作**：迫降输入进入电梯控制系统，电梯按专业方案动作，到达指定层后返回门状态和结果。
- **正常证据**：输入方式、迫降层、门状态、运行结果和控制室显示相互对应，测试过程有电梯维保单位协同。
- **异常与恢复**：不迫降或反馈不一致时记录编号、触发、楼层和状态，交专业维保处理；不得短接安全回路、修改程序或自行拆修。

#### F. 灭火器

- **作用**：为人员处置可控的初起火灾提供便携式灭火工具。
- **组成**：筒体、灭火剂、器头、保险销、铅封、喷管/喷嘴、压力或状态指示及维修标识。
- **工作**：选择与火灾类型相容的灭火剂，解除保险并按产品方法喷射；实际使用必须先报警、疏散并确认人员安全。
- **正常证据**：位置可达、类型适配、筒体无严重锈蚀变形泄漏，器头和喷管完整，保险销/铅封、压力或状态指示及标识符合产品规定。
- **异常与恢复**：失压、泄漏、严重腐蚀、使用后或达到维修/报废条件时送有资质单位处理；不得自行充装、混用药剂或把外观正常写成灭火功能合格。

#### G. 室内消火栓组件

- **作用**：通过栓阀、水带、水枪和给水系统形成室内人工取水灭火路径，按钮可按设计参与启泵或反馈。
- **组成**：箱体、栓阀、水带、水枪、接口、软管卷盘、启泵按钮和标识，具体配置按现场资料核对。
- **工作**：开启栓阀后形成水流，按钮/压力/泵组等信号按设计进入控制链；组件齐全不等于供水和反馈成立。
- **正常证据**：箱门和通道可达，组件齐全，栓阀和接口完好，水带未长期折压，按钮、泵组和控制室反馈按方案对应。
- **异常与恢复**：无水、无反馈、缺件或损坏时先确认排水、防淹和保护影响，按授权处理；不得随意关阀、短接按钮或扩大放水，测试后恢复阀门和监视。


- **原理/适用**：加压送风是向防烟楼梯间、前室等设计区域送入空气以形成防烟条件；排烟是把烟气导向室外或排烟通道。两者均依赖风机、风阀/风口、风管、控制和反馈，但服务区域与动作逻辑不同。
- **前置安全**：确认测试区域、风机和阀门编号，通知控制室及受影响人员；涉及检修执行断电、验电、挂牌和监护；测风量风压使用与方案匹配且状态合格的仪器。
- **检测方法**：按方案分别采用手动、联动和必要的现场测量；核对启动命令、风机运行、阀门实际位置、控制室反馈、区域对应及异常声音振动，不能只看电机转动。
- **恢复记录**：记录输入方式、风机/阀门编号、现场动作、运行/故障反馈、测量条件和数据来源；测试后恢复阀门、控制方式和联动监视。

### 10.3 防火门、卷帘、防火阀：分隔构件的差异

- **防火门**以门扇、门框、闭门器、释放器和密封件形成可关闭的分隔；常闭门重点看关闭可靠，常开门重点看释放后关闭和状态反馈。
- **防火卷帘**以帘板、导轨、卷轴、电机、限位和控制器形成可升降分隔；必须确认运动区域无人、无障碍，检测上升/下降/停止/限位/反馈。
- **防火阀**安装在风管系统中，重点是阀体、执行机构、释放部件、复位和位置反馈；不能把风阀、排烟阀和防火阀按同一动作逻辑处理。
- **恢复记录**：写明门的开闭状态、卷帘停止/到位位置、阀门位置、反馈、障碍物处理、复位方式和复测结果。不得用楔块、拆线、屏蔽或普通五金件掩盖故障。

### 10.4 应急照明、电话、广播：供电与信息传递的差异

- **应急照明/疏散指示**关注主备电转换、灯具点亮、方向和控制器/集中电源故障；不能以一盏灯亮代替系统状态确认。
- **消防电话**关注总机、分机/插孔、专用线路、备用电源、呼叫和双向通话清晰度；不使用普通电话线路替代。
- **应急广播**关注广播主机、功放、分区、扬声器、线路和备用电源，重点验证分区对应及按设计要求的强制切换；不以单个扬声器有声推断全分区正常。
- **恢复记录**：记录转换方式、分区/点位、通话双方或播报内容、故障提示、主备电状态、恢复动作和复核人；测试后恢复常态监视和正常广播模式。

### 10.5 消防电梯、灭火器、消火栓：专业边界的差异

- **消防电梯**是火灾联动与电梯安全控制的接口验证，不是普通电气设备启停；核对迫降输入、指定层、门状态和反馈，必须由电梯维保单位协同。
- **灭火器**是便携式初起火灾器材，重点看类型适配、位置、筒体、器头、保险销/铅封、压力或状态指示及维修/报废标识；不自行充装。
- **室内消火栓**依赖箱体、栓阀、水带、水枪、接口、按钮和给水系统；放水检测前确认排水和防淹，不能以箱内组件齐全推断供水和反馈正常。
- **恢复记录**：电梯记录迫降层、门状态和维保结论；灭火器记录编号、外观状态和送修/更换去向；消火栓记录测试点、阀门、排水、泵组/反馈和恢复状态。

### 10.6 八类故障诊断案例

| 案例 | 现象与优先假设 | 前置安全与处理 | 动作/反馈验证与记录 |
| --- | --- | --- | --- |
| 1. 排烟风机运行但无反馈 | 可能是反馈触点、输入模块、线路或点位映射异常，也可能实际运行不稳定 | 通知控制室和相关区域，按方案测试；不得拔反馈线制造故障 | 同时记录命令、现场运行、控制室反馈和故障显示；修复后复测并恢复联动 |
| 2. 加压送风阀不到位 | 可能有机械阻挡、执行器供电/传动、限位或反馈问题 | 确认阀门附近安全，检修时断电挂牌；不强行扳动带电机构 | 记录实际位置与控制器位置是否一致、风机状态和区域；维修后验证开闭及反馈 |
| 3. 防火门释放后不关闭 | 可能是释放器、闭门器、门扇变形、密封件或现场障碍 | 先保证防火分隔和人员通行安全，移除可确认的障碍；不得楔住或屏蔽门磁 | 记录释放输入、门扇关闭、状态反馈和复位；复测常态/联动状态 |
| 4. 防火卷帘中途停止 | 可能是导轨/帘面阻滞、限位、驱动、供电或控制故障 | 立即清场、设警戒并停止反复启停；不站在帘下观察 | 记录停止位置、控制方式、障碍和反馈；专业处理后验证运行、限位、反馈和恢复 |
| 5. 应急照明主备电异常 | 可能是集中电源、充电、通信、配电线路或灯具故障 | 按方案做失电/转换测试，避免影响实际疏散；电气处理需授权隔离 | 记录转换方式、灯具现象、控制器提示和恢复主电后的常态状态 |
| 6. 消防电话单点不通 | 单点异常优先查分机/插孔、端接和局部线路；多点异常再查总机、电源或主干 | 先确认通话对象和测试范围，不改接普通电话 | 分段呼叫、接听并记录通话清晰度、杂音、断续和复测结果 |
| 7. 应急广播某分区无声 | 可能是分区选择、功放通道、线路或扬声器问题 | 采用经授权的分区测试，防止误播影响现场；不接入不明负载 | 按“分区—功放—线路—扬声器”分段记录，验证播报和强制切换后恢复模式 |
| 8. 消火栓按钮动作但泵无启动/无反馈 | 可能是按钮输入、控制方式、电源、泵组、联动逻辑或反馈链异常 | 核对排水、防误启动和专业监护；不得短接启动或随意关阀 | 记录按钮输入、控制柜显示、泵动作、压力/反馈和恢复；按方案复测并上报遗留项 |

> 诊断案例用于训练“现象—假设—安全—分段验证—恢复—记录”，不是统一维修授权、固定故障代码或官方评分表。

## 11. 只读场景训练

### 场景一：排烟风机启动但控制室无反馈

**答案：** 不能判定为合格。应核对风机运行状态、反馈模块/线路、控制器显示和现场方案，修复后重新测试并记录。

**易错点：** “电机转了”只证明可能有机械动作，不等于反馈、区域和性能都正确。

### 场景二：防火门常开释放后没有关闭

**答案：** 先保护现场并核对释放器、闭门器、门体障碍和控制逻辑，不能用楔块保持开启，也不能简单屏蔽门磁故障。

### 场景三：卷帘下降时下方有人

**答案：** 立即停止测试并清场，确认警戒和防夹措施后再按方案进行。测试安全优先于完成动作。

### 场景四：应急照明测试后仍显示主电故障

**答案：** 不能结束任务。应恢复主电、检查充电和故障显示，确认常态监视和无新增故障后再记录完成。

### 场景五：消防电话分机无声

**答案：** 按总机、线路、分机/插孔、端接顺序分段排查，换用兼容部件后逐点复验，不能接普通电话替代。

### 场景六：消火栓按钮动作但泵未启动

**答案：** 核对按钮输入、控制方式、电源、泵组状态、联动逻辑和反馈；测试必须有排水、防误启动和专业监护，不能直接短接启动。

> 以上场景均为原创训练题，不是官方真题，也不代表具体鉴定站评分表。

## 12. 记录模板

| 字段 | 应记录内容 |
| --- | --- |
| 基本信息 | 项目、区域、设备编号、日期时间、操作/监护/复核人员 |
| 依据 | 标准/版本、设计文件、说明书、检测方案、评分要求 |
| 前置措施 | 告知、警戒、误动作防护、断电挂牌、排水和专业协同 |
| 测试过程 | 手动/自动/联动方式、输入、现场动作、反馈、恢复 |
| 原始结果 | 现象、测量值、故障代码、影响范围、照片/打印记录 |
| 处理过程 | 临时措施、维修/更换部件、维修单位、复测项目 |
| 结论 | 合格/不合格或待复核，遗留问题、上报对象、恢复时间 |
