# 其他消防设施项目卡

> **适用方向：消防设施检测维修保养（四级/中级工）**。本页围绕 2019 年版国家职业技能标准中设施操作、保养、维修、检测的“其他消防设施”内容学习。答案用于建立判断框架，不替代鉴定站现场评分表、设计文件、设备说明书、检测方案和专业作业许可。

## 1. 学习目标

读完本页后，应能按同一条主线学习每类设备：

```text
识别对象 → 确认安全 → 执行操作/检测 → 观察动作与反馈 → 判断异常 → 恢复状态 → 记录结果
```

重点掌握：

- 防烟排烟系统的风机、风阀、排烟口/送风口及反馈；
- 防火门、防火卷帘、防火阀的分隔作用与动作确认；
- 应急照明、疏散指示、消防电话和应急广播；
- 消防电梯迫降的接口和专业协同边界；
- 灭火器与室内消火栓组件的检查、维修和检测边界。

## 2. 先建立一张设备地图

| 设备 | 主要作用 | 检查时要证明什么 |
| --- | --- | --- |
| 送风机、送风阀/口 | 为防烟区域提供加压送风 | 风机运行、阀口到位、控制室收到反馈 |
| 排烟风机、排烟阀/口 | 排出烟气或形成排烟通路 | 风机运行、阀口动作、反馈和设计区域对应 |
| 排烟防火阀 | 按设计工况阻断火烟传播 | 动作、复位、位置反馈和本体完好 |
| 防火门/卷帘 | 形成防火分隔 | 关闭或下降到位、无阻挡、状态反馈正常 |
| 应急照明/疏散指示 | 断电或联动时提供疏散照明和方向 | 应急转换、点亮、方向、故障监视和恢复 |
| 消防电话/应急广播 | 组织指挥和传递疏散信息 | 通话清晰、分区广播和强制切换有效 |
| 消防电梯 | 火灾时按设计要求迫降并供消防使用 | 输入、迫降层、门状态和反馈，不擅改电梯安全逻辑 |
| 灭火器/消火栓 | 供人员处置初起火灾 | 类型、位置、组件和有效性，不把外观完好当成系统合格 |

## 3. 防烟排烟系统

### 3.1 组成与原理

系统通常包括机械加压送风机、排烟风机、风管、送风阀/送风口、排烟阀/排烟口、排烟防火阀、挡烟垂壁、控制柜、联动线路和反馈装置。具体配置以设计文件和竣工图为准。

理解信号链：

```text
火灾信号/手动指令
→ 控制器或控制柜发出启动命令
→ 相关风阀/排烟口动作
→ 风机运行
→ 运行、阀位或故障反馈返回
→ 控制室核对区域和状态
```

> **注意：** 不能把“风机转动”直接等同于“排烟系统合格”。还要核对阀门位置、区域对应、运行状态、反馈以及方案要求的风量/风压等数据。

### 3.2 操作与检测卡

1. 核对区域、设备编号、设计逻辑和测试方案；
2. 通知控制室、相关楼层和可能受影响人员，采取防误动作措施；
3. 确认设备处于准工作状态，风机检修时执行断电、挂牌和监护；
4. 按方案分别执行手动启动、自动联动或阀门动作测试；
5. 观察风机启停、旋转和声音振动，核对阀门是否到位；
6. 在控制室核对启动、运行、故障、阀位等反馈；
7. 按方案恢复阀门、风机、控制柜和联动状态，确认无遗留故障；
8. 记录区域、方式、动作、反馈、异常、测量数据和复测结果。

### 3.3 保养、维修与异常

- 保养：清洁风机、控制柜、阀口和执行机构，检查固定件、端子、线路、皮带/轴承和障碍物；
- 维修：风机、电机、执行器、限位、易熔片或反馈部件按产品文件和资质边界处理；
- 异常：风机不启动、阀门卡涩、反馈不一致、异响振动、风量/风压异常、联动区域错误；
- 不能通过拆线、拔模块、长期屏蔽或擅改逻辑“消除”故障；
- GB 51251-2017 的维护条款可用于建立周期意识，但具体检测项目和判定必须核对现行版本及项目方案。

## 4. 防火门、防火卷帘和防火阀

### 4.1 防火门

防火门学习四件事：门体完整、闭门可靠、顺序正确、状态可反馈。

检查内容：

- 门扇、门框、合页、闭门器、密封件和铭牌完好；
- 常闭门不应被楔住、插销固定或堆物阻挡；
- 双扇门关闭顺序符合产品和设计要求；
- 常开门的释放器、门磁/状态开关和监控器状态正常；
- 联动释放后应按设计关闭，控制器显示与现场状态一致。

维修时不得随意打孔、加装普通插销或使用不兼容部件。门体耐火完整性受损时，不能用普通五金件替代专业维修。

### 4.2 防火卷帘

组成包括帘板、导轨、卷轴、电机、控制器、限位、手动装置、联动输入/输出和反馈。

操作和检测：

1. 清理下方和两侧区域，确认无人员、车辆和障碍物；
2. 核对手动、自动、联动测试条件；
3. 观察上升、下降、停止、限位和反馈；
4. 发现卡阻、下滑、异响或不能限位时停止反复操作，隔离区域并报修；
5. 测试后恢复控制方式、位置和故障状态，完成复测记录。

> **安全红线：** 卷帘动作区域严禁站人；不得用拆线或屏蔽代替维修，不得把帘板损坏简单当作控制器故障。

### 4.3 防火阀

防火阀应关注阀体、执行机构、释放部件、位置和反馈。检查开启/关闭动作、复位灵活性、风道障碍和反馈一致性；具体动作条件和维护周期以适用标准、设计文件、产品说明书和检测方案为准。

## 5. 应急照明和疏散指示

### 5.1 系统组成

常见组成包括消防应急照明控制器、集中电源或应急照明配电箱、应急灯具、疏散指示标志、蓄电池、通信和配电线路。系统类型不同，控制方式和接线方式也不同。

### 5.2 学习与检测闭环

- 看控制器、集中电源/配电箱是否有故障；
- 看灯具安装、方向、标志面和遮挡情况；
- 按方案测试主电失电、联动或手动应急转换；
- 观察灯具点亮、疏散方向和故障反馈；
- 恢复主电，确认充电、常态显示和无新增故障；
- 记录系统类型、设备编号、转换方式、现象、依据和复测结果。

不得把普通照明、插座或其他负载接入应急照明系统输出回路；不得擅自改变疏散方向或以普通灯具替代消防应急灯具。照度、转换时间和持续时间必须引用适用标准、设计文件和检测方案，不能凭记忆填写。

## 6. 消防电话和应急广播

### 6.1 消防电话

组成通常包括消防电话总机、分机/插孔、线路和备用电源。检测时应核对总机与分机/插孔的呼叫、接听、通话清晰度、指示和故障监视。

故障排查顺序：

```text
确认对象和区域 → 查线路/端接 → 查总机/分机状态 → 分段测试 → 更换兼容部件 → 逐点复验
```

不得把普通电话系统或不明线路替代消防电话专线。记录通话双方、区域、结果、杂音/断续现象和复测结果。

### 6.2 应急广播

组成通常包括广播控制设备、功放、分区选择、扬声器、线路和备用电源。重点检测：

- 主机和功放无故障；
- 分区选择与现场区域对应；
- 火灾联动时强制切换逻辑符合设计；
- 播报清晰，扬声器和线路无明显断路；
- 测试后恢复正常广播/监视状态。

无声或断续时按“分区—功放—线路—扬声器”分段排查，不用不明负载替代扬声器。

## 7. 消防电梯迫降

消防电梯迫降涉及火灾报警/联动控制器、输入输出模块、电梯控制接口、消防电梯控制系统和反馈信号。学习重点不是修改电梯程序，而是核对：

```text
迫降输入 → 电梯动作 → 到达指定层 → 门状态/运行反馈 → 控制室显示
```

测试前必须联系电梯维保单位，确认轿厢和井道安全，设置警戒并避免影响正常使用。不得短接安全回路、强行改写程序或由非专业人员拆修电梯控制系统。异常时记录电梯编号、触发方式、迫降层、门状态、反馈和维保单位处理结果。

## 8. 灭火器与室内消火栓组件

### 8.1 灭火器

检查：类型是否适配、数量和位置是否符合配置、筒体有无严重锈蚀/变形/泄漏、保险销和铅封是否完好、喷管和器头是否完整、压力指示是否处于产品规定状态、维修/报废标识是否清楚。

失压、泄漏、严重腐蚀、使用后或达到维修/报废条件的灭火器，应送有资质单位处理。不得自行充装或混用灭火剂。灭火器只适用于人员安全且火势可控的初起火灾，先报警、疏散并选择相容灭火剂。

### 8.2 室内消火栓

组件通常包括箱体、栓阀、水带、水枪、接口、软管卷盘和启泵按钮（如设）。检查箱门和标志、组件齐全、栓阀启闭、接口密封、水带状态、按钮报警和泵反馈。

放水测试前要核对方案、排水路径和防淹措施；测试后恢复阀门、控制柜、报警状态和记录。不得锁闭、遮挡、挪作他用或长期折压水带。水带、水枪、栓阀和按钮损坏时按同规格消防产品更换并复验。

## 9. 通用故障与恢复卡

| 现象 | 优先核对 | 不能直接做的事 |
| --- | --- | --- |
| 风机不启动 | 电源、控制方式、保护、联动输入、反馈线路 | 反复强启或拆线屏蔽 |
| 风阀不到位 | 障碍、执行器、限位、供电、反馈 | 强行扳动带电机构 |
| 卷帘卡阻 | 导轨、帘面、限位、电机和区域安全 | 在下方站人或反复下降 |
| 应急灯不亮 | 主备电、集中电源、线路、灯具故障 | 接普通电源临时替代 |
| 广播无声 | 分区、功放、线路、扬声器 | 接入不明负载 |
| 电话不通 | 总机、分机/插孔、线路端接 | 改接普通电话线 |
| 电梯不迫降 | 输入、接口、反馈、维保状态 | 短接安全回路 |
| 消火栓无水/无反馈 | 阀门、水源、泵组、按钮、排水和联动 | 随意关阀、拆线或大流量放水 |

每个异常都必须形成：

```text
发现时间 → 现象与影响范围 → 临时防护/上报 → 授权维修 → 复测 → 恢复自动/联动/监视 → 复核记录
```

## 10. 只读场景训练

### 场景一：排烟风机启动但控制室无反馈

**答案：** 不能判定为合格。应核对风机运行状态、反馈模块/线路、控制器显示和现场方案，修复后重新测试并记录。

**易错点：** “电机转了”只证明可能有机械动作，不等于反馈、区域和性能都正确。

### 场景二：防火门常开释放后没有关闭

**答案：** 先保护现场并核对释放器、闭门器、门体障碍和控制逻辑，不能用楔块保持开启，也不能简单屏蔽门磁故障。

### 场景三：卷帘下降时下方有人

**答案：** 立即停止测试并清场，确认警戒和防夹措施后再按方案进行。测试安全优先于完成动作。

### 场景四：应急照明测试后仍显示主电故障

**答案：** 不能结束任务。应恢复主电、检查充电和故障显示，确认常态监视和无新增故障后再记录完成。

### 场景五：消防电话分机无声

**答案：** 按总机、线路、分机/插孔、端接顺序分段排查，换用兼容部件后逐点复验，不能接普通电话替代。

### 场景六：消火栓按钮动作但泵未启动

**答案：** 核对按钮输入、控制方式、电源、泵组状态、联动逻辑和反馈；测试必须有排水、防误启动和专业监护，不能直接短接启动。

> 以上场景均为原创训练题，不是官方真题，也不代表具体鉴定站评分表。

## 11. 记录模板

| 字段 | 应记录内容 |
| --- | --- |
| 基本信息 | 项目、区域、设备编号、日期时间、操作/监护/复核人员 |
| 依据 | 标准/版本、设计文件、说明书、检测方案、评分要求 |
| 前置措施 | 告知、警戒、误动作防护、断电挂牌、排水和专业协同 |
| 测试过程 | 手动/自动/联动方式、输入、现场动作、反馈、恢复 |
| 原始结果 | 现象、测量值、故障代码、影响范围、照片/打印记录 |
| 处理过程 | 临时措施、维修/更换部件、维修单位、复测项目 |
| 结论 | 合格/不合格或待复核，遗留问题、上报对象、恢复时间 |
