# 5. 电气消防基础知识

## 一、电工学基础（必记概念）

- **电流（I）**：电荷的定向移动，单位安培（A）。
- **电压（U）**：两点间的电势差，单位伏特（V）。
- **电阻（R）**：导体对电流的阻碍，单位欧姆（Ω）；欧姆定律 U = I × R。
- **电路**：由电源、负载、导线、开关组成的闭合回路。
- **串联 / 并联**：
  - 串联：电流相同、电压分压。
  - 并联：电压相同、电流分流。
- **交流电 / 直流电**：市电为交流电（AC，220 V / 380 V）；电池为直流电（DC）。
- **三相电**：工业常用三相交流电（L1/L2/L3 + N 中性线 + PE 保护地线）。

## 二、电气火灾的主要原因

电气火灾占火灾成因比例很高，主要由于：

1. **过载（过负荷）**：线路承载电流超过安全值，温度升高引燃绝缘。
2. **短路**：相线与相线 / 相线与零线直接接触，电流剧增、产生高温电弧。
3. **接触不良**：接头松动、氧化，接触电阻过大发热。
4. **电弧 / 电火花**：开关、接触不良、绝缘破损产生。
5. **电气设备选型 / 使用不当**：如高温灯具靠近可燃物、私拉乱接。

## 三、电气线路与设备防火常识

- 导线选型：按载流量、环境条件选择截面与绝缘等级。
- 敷设要求：穿管保护、避免高温 / 潮湿 / 腐蚀环境，远离可燃物。
- 保护措施：
  - **短路保护**、**过载保护**（断路器 / 熔断器）应在故障瞬间切断。
  - **剩余电流保护（漏电保护）**：防触电和漏电火灾。
- 配电箱 / 控制柜：保持通风、定期除尘、紧固接头。
- 爆炸危险环境：使用**防爆电气设备**（见下）。

## 四、防爆电气基本知识

- 爆炸性环境分：**气体爆炸环境（Zone 0/1/2）**、**粉尘爆炸环境（Zone 20/21/22）**。
- 防爆电气设备标志 **Ex**，按防爆型式分：隔爆型（d）、增安型（e）、本安型（i）、正压型（p）等。
- 在易燃易爆场所（加油站、化工车间）必须使用对应防爆等级的电气设备。

## 五、零基础易错点

- 欧姆定律 U=IR，计算题常考。
- 电气火灾主因记「过载、短路、接触不良、电弧火花、使用不当」五类。
- 漏电保护防触电与漏电火灾；短路 / 过载保护防线路火灾——**作用不同不要混**。
- 防爆场所必须用 **Ex** 标志设备，分级分区（Zone）。
