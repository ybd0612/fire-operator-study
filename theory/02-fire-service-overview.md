# 2. 消防工作概述

## 本章学习目标

学完本章，你应该能说清消防工作的方针、原则、单位主体责任，以及消防设施操作员为什么必须“监控—报告—记录”而不能擅自改变系统。

## 一、消防工作到底解决什么问题

消防工作不是只在着火后灭火，而是围绕火灾风险建立一套持续工作的防线：预防火灾发生、及时发现异常、控制火势和烟气、保障人员疏散、组织专业救援，并在事后查明原因、整改隐患。

因此，消防设施操作员的日常值班同样属于消防工作。一个没有及时发现的故障，可能使报警、联动或疏散功能在真正需要时失效。

## 二、消防工作方针

**预防为主，防消结合。**

- **预防为主**：把减少火灾发生的可能性放在首位，例如保持疏散通道畅通、及时处理故障、规范用电和动火。
- **防消结合**：不能只做日常预防，还要保持报警、灭火、排烟、疏散和救援条件，确保火灾发生后能够及时响应。

## 三、消防工作原则

**政府统一领导、部门依法监管、单位全面负责、公民积极参与。**

对操作员最重要的是“单位全面负责”：单位要建立制度、配备设施、组织检查和演练，并保证建筑消防设施完好有效。操作员是单位消防安全管理体系中的执行岗位，不等于可以替代单位负责人作出所有管理决定。

## 四、单位消防安全职责如何理解

《消防法》第十六条规定的单位职责可以按三个层次理解：

1. **建制度**：落实责任制，制定消防安全制度和操作规程。
2. **保设施**：配置设施器材，设置标志，定期检查、维修，保证完好有效。
3. **保通道**：保持疏散通道、安全出口、消防车通道畅通。
4. **查隐患**：组织防火检查，及时消除火灾隐患。
5. **做检测**：对建筑消防设施按规定进行全面检测，保存记录。
6. **做演练**：组织有针对性的消防演练。
7. **履行其他法定义务**：执行法律法规规定的其他要求。

这里的“全面检测”是单位责任，不等于值班员一个人随意拿仪器测量；检测应由符合要求的人员、机构和方案组织实施。

## 五、四类主体如何接力完成消防工作

| 主体 | 主要作用 | 发现设施异常后通常关注什么 |
| --- | --- | --- |
| 政府 | 统一领导和组织公共消防工作 | 公共安全、区域协同和应急资源 |
| 部门 | 依法监管本行业或领域 | 监管职责、检查和执法边界 |
| 单位 | 对本单位消防安全全面负责 | 制度、设施、人员、检测、隐患和演练 |
| 公民/员工 | 遵守规定、发现并报告火灾风险、参与必要处置 | 先保护人员，再报警、疏散和报告 |

在岗位现场还要继续分工：操作员负责发现、核实、操作授权范围内的功能和记录；维修/检测人员负责专业判断和技术处理；单位负责人或授权管理人员负责停用、重大风险、资源和整改决策。不是“谁先发现，谁就可以决定所有事情”。

### 一条故障责任链

```text
发现异常
→ 操作员记录并报告
→ 责任人评估影响和临时防护
→ 授权维修/检测人员处理
→ 复测人员确认结果
→ 单位完成恢复、销项和复盘
```

## 五、岗位场景：为什么要记录和报告

**场景**：你发现某回路长期故障，主管说“先屏蔽，月底再修”。

正确处理不是简单拒绝或私自恢复，而是：记录故障位置、时间和影响范围 → 按单位制度报告 → 评估保护范围 → 落实临时防护和告知 → 由授权人员安排维修 → 维修后测试、恢复并留档。

## 六、岗位责任边界

| 事项 | 单位/负责人 | 操作员或检测维修人员 |
| --- | --- | --- |
| 建立制度、落实责任 | 组织建立并监督执行 | 按制度和授权执行，发现缺陷报告 |
| 消防设施运行 | 保证资金、人员和设施条件 | 监视、操作、保养、维修或检测相应项目 |
| 重大停用、改造和风险决策 | 组织审批、告知和临时防护 | 提供事实记录，不擅自决定重大变更 |
| 事故或火灾处置 | 组织预案、外部协同和复盘 | 按预案操作、报告、记录并保护自身安全 |

### 三类工作不要混淆

- **值班监控**：持续观察状态、接收信息、记录和报告；
- **维护保养**：保持设备清洁、连接和功能处于规定状态；
- **检测维修**：按方案测试、判定、处理故障并复测。

“看见控制器正常”不能代替全面检测；“做过一次检测”也不能代替持续值班和日常巡查。
