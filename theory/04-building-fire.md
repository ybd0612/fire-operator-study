# 4. 建筑防火基础知识

## 本章学习目标

学完本章，你应该能看懂建筑防火中“分隔、疏散、间距、通道”这些词，理解它们分别阻止什么风险，并能在技能训练中识别防火门、卷帘、防烟分区和疏散指示。

## 一、建筑防火在解决什么问题

火灾扩大通常有两条路径：火焰和热量向邻近区域传播，烟气沿走道、楼梯间、竖井和其他开口扩散。建筑防火通过耐火构件、防火分隔、防烟分区、合理疏散和消防车道，把火灾限制在一定范围，并给人员撤离和消防救援争取时间。

## 二、现行规范入口

建筑防火学习应优先关注现行的 **GB 55037-2022《建筑防火通用规范》**。该规范自 2023-06-01 起实施，属于全文强制性工程建设规范。GB 50016《建筑设计防火规范》仍可能作为配套标准被引用，但其与 GB 55037 不一致的部分，应以 GB 55037 为准；不能把旧版 GB 50016 的所有条文都当作无条件答案。

建筑高度、住宅/公共建筑分类、疏散出口、耐火等级等具体数值，要以现行标准、建筑用途和题干条件综合判断。本站只讲理解框架，不把单一口诀当成所有场景的判定标准。

## 三、几个容易混淆的概念

- **防火分区**：重点限制火焰和火势扩大，通常通过防火墙、防火门、防火卷帘等分隔。
- **防烟分区**：重点限制烟气蔓延，常配合挡烟垂壁和排烟系统。
- **防火间距**：相邻建筑之间的距离，用于降低火灾相互蔓延风险。
- **耐火极限**：构件在标准耐火试验中保持承载、完整或隔热性能的时间。
- **耐火等级**：建筑整体耐火能力的等级概念，不能简单等同于某一个构件的耐火极限。

## 四、建筑分类不要死背一条数字

住宅、公共建筑、厂房和仓库的分类会结合使用性质、建筑高度、层数、火灾危险性和规范适用条件。建筑高度的计算也有规范定义。

因此，遇到“某建筑属于哪一类”“需要哪种楼梯间”等题目，要先读清建筑类型、用途和题干条件，再查现行 GB 50016；不能用“超过某层就是高层”的单一口诀替代完整判断。

## 五、疏散系统怎么工作

安全疏散的目标是让人员从危险区域到达安全区域。学习时按“看得见、走得通、出得去”理解：

1. 应急照明和疏散指示帮助人员找到方向；
2. 疏散走道、楼梯和安全出口保持畅通；
3. 防火门、防烟楼梯间等减少烟气进入疏散路径；
4. 火灾时通常不乘普通电梯，应按现场指挥和疏散预案行动。

“安全出口一般不少于两个”只能作为常见理解，具体数量和布置必须结合现行规范及建筑条件判断。

## 六、防火分隔还要看哪些小知识点

### 1. 建筑构件的三个耐火性能

- **承载能力**：构件在火灾作用下还能否承受设计荷载；
- **完整性**：构件是否出现穿透性裂缝、孔洞或失去阻止火焰和热气穿过的能力；
- **隔热性**：构件背火面温升是否控制在规定范围内。

耐火极限是构件在标准耐火试验中保持相关性能的时间，不等于“这栋建筑能烧多久”。建筑耐火等级则是对建筑整体耐火能力的分级，判断时要看建筑构件组合和适用标准。

### 2. 防火门、防火窗、防火卷帘和防火阀

这些设施都与防火分隔有关，但作用和动作方式不同：

| 设施 | 主要学习重点 |
| --- | --- |
| 防火门 | 门扇、门框、闭门器、顺序器、释放器、门磁/监控反馈 |
| 防火窗 | 窗体完整性、关闭状态和耐火产品标识 |
| 防火卷帘 | 帘板、导轨、电机、限位、手动/联动下降和反馈 |
| 防火阀 | 阀体、执行机构、释放部件、启闭位置和反馈 |

考试或检测题出现“门不能自行关闭、卷帘下方有障碍、阀位反馈不一致”时，不能只回答“复位”，应先处理安全和故障原因，再验证恢复。

### 3. 消防车道和消防救援条件

建筑防火不仅保护室内人员，也要保证消防救援能够接近建筑。学习时应关注消防车道、消防车登高操作场地、消防水源和水泵接合器是否被占用或遮挡。具体宽度、转弯半径、间距和设置条件依建筑类别、建筑高度及现行规范判断，不能脱离题干死背单一数字。

## 七、技能连接：为什么卷帘下面不能堆物

防火卷帘下降后承担防火分隔作用。如果卷帘下方堆物，可能造成无法完全下降、密封不良或人员伤害。技能操作前要确认区域安全，操作后要核对卷帘位置、反馈和系统恢复状态。

## 八、考试判断顺序

遇到建筑防火题，可以按下面顺序思考：

1. 先判断建筑用途、规模、层数/高度和题干场景；
2. 再判断问题属于防火分隔、疏散、防烟还是消防救援；
3. 查看相关构件或设施是否完整、关闭、畅通、可反馈；
4. 最后再查现行标准的具体数值或条件。

> **不要先套口诀。** 题干条件没有明确时，只能给出原则判断，不能擅自补全建筑类别和参数。
