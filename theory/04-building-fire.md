# 4. 建筑防火基础知识

## 本章学习目标

学完本章，你应该能看懂建筑防火中“分隔、疏散、间距、通道”这些词，理解它们分别阻止什么风险，并能在技能训练中识别防火门、卷帘、防烟分区和疏散指示。

## 一、建筑防火在解决什么问题

火灾扩大通常有两条路径：火焰和热量向邻近区域传播，烟气沿走道、楼梯间、竖井和其他开口扩散。建筑防火通过耐火构件、防火分隔、防烟分区、合理疏散和消防车道，把火灾限制在一定范围，并给人员撤离和消防救援争取时间。

## 二、现行规范入口

建筑防火学习应优先关注现行的 **GB 55037-2022《建筑防火通用规范》**。该规范自 2023-06-01 起实施，属于全文强制性工程建设规范。GB 50016《建筑设计防火规范》仍可能作为配套标准被引用，但其与 GB 55037 不一致的部分，应以 GB 55037 为准；不能把旧版 GB 50016 的所有条文都当作无条件答案。

建筑高度、住宅/公共建筑分类、疏散出口、耐火等级等具体数值，要以现行标准、建筑用途和题干条件综合判断。本站只讲理解框架，不把单一口诀当成所有场景的判定标准。

## 三、几个容易混淆的概念

- **防火分区**：重点限制火焰和火势扩大，通常通过防火墙、防火门、防火卷帘等分隔。
- **防烟分区**：重点限制烟气蔓延，常配合挡烟垂壁和排烟系统。
- **防火间距**：相邻建筑之间的距离，用于降低火灾相互蔓延风险。
- **耐火极限**：构件在标准耐火试验中保持承载、完整或隔热性能的时间。
- **耐火等级**：建筑整体耐火能力的等级概念，不能简单等同于某一个构件的耐火极限。

## 四、把五个概念真正分开

### 1. 防火分区：给“火势”划边界

防火分区是建筑内部用具有一定耐火能力的构件划出的区域。它主要解决的问题是：**火焰、热量和燃烧产物不能在建筑内部无限制地向相邻区域扩散**，为人员疏散、消防救援和灭火争取时间。

可以把它理解为建筑内部的“防火隔间”。它通常由以下要素共同形成：

- **分隔构件**：防火墙、楼板等相对固定的构件；
- **开口防护**：防火门、防火窗、防火卷帘等；
- **穿越部位处理**：管道、电缆、风管穿墙或穿楼板处的防火封堵；
- **边界完整性**：不能因为门常开、卷帘下有障碍、墙体被随意开洞而失去分隔作用。

**例子：**商场某区域发生火灾，防火卷帘按设计下降并形成分隔，目的不是“把火立刻灭掉”，而是限制火焰和热量向相邻区域扩大。

### 2. 防烟分区：给“烟气”划边界

防烟分区是为了控制烟气在一定范围内的水平扩散，使排烟系统能够在相对明确的区域内组织烟气流向。它主要解决的是：**人员还没有被火焰直接烧到，但可能先被烟气遮挡视线、呛伤或窒息**。

常见组成和配合关系包括：

- 挡烟垂壁、梁或其他能限制烟气水平扩散的构造；
- 排烟口、排烟阀、排烟风机和排烟管道；
- 防烟楼梯间、前室及机械加压送风设施；
- 火灾报警和联动控制系统提供启动条件、控制指令或状态反馈。

**例子：**走道内产生烟气时，挡烟垂壁帮助烟气停留在设计区域，排烟口和排烟风机负责按设计路径排出；这与防火墙直接阻挡火焰和热量不是同一件事。

### 3. 防火间距：给“建筑之间”留安全距离

防火间距不是建筑内部的房间，也不是墙体本身，而是**相邻建筑之间需要保持的空间距离**。它主要降低一栋建筑发生火灾后，通过热辐射、飞火或火焰蔓延影响另一栋建筑的风险。

判断防火间距时不能只背一个固定数字，通常要结合建筑的用途、耐火等级、建筑高度、外墙和屋顶开口等条件，按现行适用标准判断。

**例子：**两栋建筑之间距离较小，且外墙开口较多，即使两栋建筑内部都有防火门，也不能简单认为建筑之间的火灾蔓延风险已经解决，因为防火门主要处理建筑内部开口。

### 4. 耐火极限：看“一个构件能坚持多久”

耐火极限是针对**具体构件或构件组合**的性能概念。例如防火墙、防火门、楼板、梁、柱、屋顶承重构件，都可能有相应的耐火性能要求。

在规定的标准耐火试验条件下，构件从受到火作用开始，到不能继续满足某项性能要求为止的时间，称为该项性能的耐火极限。它通常要看三个指标：

- **承载能力**：梁、柱、楼板等承重构件还能不能承受规定荷载；
- **完整性**：构件有没有出现让火焰和高温烟气穿透的裂缝、孔洞或其他失效；
- **隔热性**：构件背火面温升是否超过规定限值。

所以，“耐火极限两小时”不能简单理解为“这个构件两小时后一定烧毁”，而是说明在规定试验条件下，它针对相应性能至少维持到规定时间。不同构件关注的性能指标可能不同。

### 5. 耐火等级：看“整栋建筑的构件组合水平”

耐火等级是对建筑整体耐火能力进行分级的概念。它不是给某一扇门、某一堵墙或某一根柱子单独贴的标签，而是综合考虑建筑中的墙、柱、梁、楼板、屋顶承重构件、疏散构件等主要构件，以及它们各自应满足的耐火性能要求。

在常用的建筑防火学习框架中，耐火等级通常分为：

| 等级 | 零基础理解 | 学习时应抓住的重点 |
| --- | --- | --- |
| **一级耐火等级** | 整体耐火能力要求最高的一档，主要构件通常需要采用耐火性能较强、体系较完整的做法 | 不是“某一构件特别耐火”就能代表一级，而是主要构件组合都要满足相应要求 |
| **二级耐火等级** | 整体耐火能力较高，适用于许多常见建筑，但具体适用范围要看建筑性质和条件 | 不能把二级理解成“所有构件都比一级少一个固定小时” |
| **三级耐火等级** | 整体耐火能力要求低于一、二级，构件材料和允许条件受到更多限制 | 需要结合建筑用途、层数、高度和防火分隔条件判断 |
| **四级耐火等级** | 常用学习框架中整体耐火能力要求最低的一档，适用范围和建筑条件限制更严格 | 不能脱离具体建筑类别和现行规范自行判断是否允许采用 |

**最重要的关系是：**

```text
单个构件的耐火极限
→ 参与建筑构件组合和防火设计
→ 形成建筑的耐火等级
```

例如，一栋建筑的防火门耐火性能较好，并不意味着整栋建筑就是一级耐火等级；反过来，一栋建筑标注了某个耐火等级，也不意味着其中每一个构件都使用完全相同的耐火极限。具体构件要求还要回到建筑类型、部位、材料和现行标准表格核对。

### 6. 用一个生活化比喻记忆

- **防火分区**：像房子内部的防火隔间，限制火势从一个区域跑到另一个区域；
- **防烟分区**：像控制烟雾的“分区边界”，让烟气不要一下子铺满整层；
- **防火间距**：像两栋房子之间留出的安全距离；
- **耐火极限**：像测试一扇门、一堵墙或一根柱子能在规定火作用下坚持多久；
- **耐火等级**：像给整栋建筑的防火结构体系评定等级。

### 7. 五个概念的判断顺序

遇到题目时，先问自己问题的对象是谁：

1. 问建筑内部限制火势范围，优先想到**防火分区**；
2. 问建筑内部限制烟气扩散，优先想到**防烟分区**；
3. 问相邻建筑之间的距离，优先想到**防火间距**；
4. 问一堵墙、一扇门、一根柱子能保持性能多久，优先想到**耐火极限**；
5. 问整栋建筑属于哪一档整体耐火能力，优先想到**耐火等级**。

> 这里的“一级、二级、三级、四级”是耐火等级的分级框架，不是考试中所有建筑都可以只靠等级名称直接判定。具体建筑能否采用某等级、构件需要满足什么耐火性能，必须结合建筑用途、高度、层数、构件部位和现行标准表格核对。

## 五、建筑分类不要死背一条数字

住宅、公共建筑、厂房和仓库的分类会结合使用性质、建筑高度、层数、火灾危险性和规范适用条件。建筑高度的计算也有规范定义。

因此，遇到“某建筑属于哪一类”“需要哪种楼梯间”等题目，要先读清建筑类型、用途和题干条件，再查现行 GB 50016；不能用“超过某层就是高层”的单一口诀替代完整判断。

## 五、疏散系统怎么工作

安全疏散的目标是让人员从危险区域到达安全区域。学习时按“看得见、走得通、出得去”理解：

1. 应急照明和疏散指示帮助人员找到方向；
2. 疏散走道、楼梯和安全出口保持畅通；
3. 防火门、防烟楼梯间等减少烟气进入疏散路径；
4. 火灾时通常不乘普通电梯，应按现场指挥和疏散预案行动。

“安全出口一般不少于两个”只能作为常见理解，具体数量和布置必须结合现行规范及建筑条件判断。

## 六、防火分隔还要看哪些小知识点

### 1. 建筑构件的三个耐火性能

- **承载能力**：构件在火灾作用下还能否承受设计荷载；
- **完整性**：构件是否出现穿透性裂缝、孔洞或失去阻止火焰和热气穿过的能力；
- **隔热性**：构件背火面温升是否控制在规定范围内。

耐火极限是构件在标准耐火试验中保持相关性能的时间，不等于“这栋建筑能烧多久”。建筑耐火等级则是对建筑整体耐火能力的分级，判断时要看建筑构件组合和适用标准。

### 2. 防火门、防火窗、防火卷帘和防火阀

这些设施都与防火分隔有关，但作用和动作方式不同：

| 设施 | 主要学习重点 |
| --- | --- |
| 防火门 | 门扇、门框、闭门器、顺序器、释放器、门磁/监控反馈 |
| 防火窗 | 窗体完整性、关闭状态和耐火产品标识 |
| 防火卷帘 | 帘板、导轨、电机、限位、手动/联动下降和反馈 |
| 防火阀 | 阀体、执行机构、释放部件、启闭位置和反馈 |

考试或检测题出现“门不能自行关闭、卷帘下方有障碍、阀位反馈不一致”时，不能只回答“复位”，应先处理安全和故障原因，再验证恢复。

### 3. 消防车道和消防救援条件

建筑防火不仅保护室内人员，也要保证消防救援能够接近建筑。学习时应关注消防车道、消防车登高操作场地、消防水源和水泵接合器是否被占用或遮挡。具体宽度、转弯半径、间距和设置条件依建筑类别、建筑高度及现行规范判断，不能脱离题干死背单一数字。

## 七、技能连接：为什么卷帘下面不能堆物

防火卷帘下降后承担防火分隔作用。如果卷帘下方堆物，可能造成无法完全下降、密封不良或人员伤害。技能操作前要确认区域安全，操作后要核对卷帘位置、反馈和系统恢复状态。

## 八、考试判断顺序

遇到建筑防火题，可以按下面顺序思考：

1. 先判断建筑用途、规模、层数/高度和题干场景；
2. 再判断问题属于防火分隔、疏散、防烟还是消防救援；
3. 查看相关构件或设施是否完整、关闭、畅通、可反馈；
4. 最后再查现行标准的具体数值或条件。

> **不要先套口诀。** 题干条件没有明确时，只能给出原则判断，不能擅自补全建筑类别和参数。
