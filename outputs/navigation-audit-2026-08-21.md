# 顶部栏目与左侧侧边栏对应关系审查

> 审查日期：2026-08-21
> 审查方式：静态读取 VitePress 导航配置、首页学习路径和主要课程页链接；未启动开发服务器，未进行浏览器点击。
> 结论性质：本报告只定位导航结构与点击体验问题，不修改站点代码。

## 一、结论摘要

你的感觉是对的：目前不是单个链接失效，而是**顶部导航、首页侧边栏、理论/技能页侧边栏使用了三套不同粒度的信息架构**。链接大多能到达有效页面，但用户从顶部栏目进入后，左侧导航会切换成另一套上下文，导致“栏目名称—落地页—左侧菜单”之间不完全对应。

最明显的问题有三个：

1. **顶部栏目是入口级，左侧菜单是内容级，但两者没有形成明确的父子关系**。例如“理论考试”直接落到第 1 章，而左侧菜单显示十章；“技能操作”直接落到“设施监控”，但站点主线实际是“操作 → 保养 → 维修 → 检测”。
2. **进入理论页或技能页后，左侧侧边栏会完全替换首页/训练总览菜单**。这意味着用户在课程页中看不到“零基础导学、技能路线图、只读训练、综合学习课”等上层入口，只能依赖顶部导航或浏览器返回。
3. **顶部栏目没有覆盖侧边栏中的关键学习入口**。`核心术语表`、`技能考核路线图`、`综合学习课`、`权威依据与版本边界`、`标准逐条映射`都只在首页侧边栏出现；用户从理论/技能页进入时，这些入口的可见性和位置会变化。

## 二、当前结构

### 顶部导航

| 显示文本 | 当前目标 | 实际含义 |
|---|---|---|
| 首页 | `/` | 站点首页 |
| 考核说明 | `/exam-guide` | 考试信息说明 |
| 零基础导学 | `/beginner-guide` | 学习路线与前置概念 |
| 只读训练 | `/training` | 训练总览 |
| 理论考试 | `/theory/01-professional-ethics` | 理论十章中的第 1 章 |
| 技能操作 | `/skill/01-monitoring` | 技能五项中的第 1 项“设施监控” |

### `/` 路径下的左侧菜单

1. 开始学习：首页、考核说明、零基础导学、核心术语表、来源、技能路线图、综合学习课、标准映射
2. 只读训练：训练总览、理论训练、技能训练、题源说明
3. 理论考试：十章理论
4. 技能操作考核：五项职业功能 + 三类设备项目卡

### `/theory/` 路径下的左侧菜单

只保留“理论考试 · 知识点”及十章理论，不再显示首页、学习路线和训练入口。

### `/skill/` 路径下的左侧菜单

只保留“技能操作考核 · 职业功能”及五项职业功能、三类设备项目卡，不再显示首页、学习路线和训练入口。

## 三、可复现的“点起来奇怪”路径

### 路径 A：顶部“理论考试”与落地页不匹配

`首页 → 顶部“理论考试” → 职业道德`

用户通常会把“理论考试”理解为一个总览或理论入口页，但实际直接进入第 1 章；左侧标题变成“理论考试 · 知识点”，看起来像已经进入章节内部。若用户想先看理论学习说明或训练入口，需要再依赖其他菜单。

**问题级别：P1（信息架构误导）**

### 路径 B：顶部“技能操作”把用户带到非主线起点

`首页 → 顶部“技能操作” → 设施监控`

当前用户目标是“检测维修保养”。站点正文明确把设施监控定位为基础，主线是“设施操作、设施保养、设施维修、设施检测”。但顶部“技能操作”却直接把用户落到“设施监控”，容易让用户误以为监控是当前报考方向的首要/完整入口；同时左侧菜单还把五项职业功能和设备项目卡平铺在一起。

**问题级别：P1（学习主线误导）**

### 路径 C：从理论页无法直接看到训练与学习路线

`首页 → 顶部“理论考试” → 第 1 章 → 查看左侧菜单`

进入理论页后，首页侧边栏中的“只读训练”“技能考核路线图”“综合学习课”“核心术语表”等全部消失。用户若想从某章跳到训练，必须回到顶部“只读训练”或返回首页。

**问题级别：P1（上下文断裂）**

### 路径 D：从技能页无法回到同一套课程入口

`首页 → 顶部“技能操作” → 设施监控 → 查看左侧菜单`

进入技能页后，用户只能看到技能五项和设备项目卡；“技能路线图”本身不在当前侧边栏，“只读训练”也不在当前侧边栏。正文中的路线说明与左侧菜单被拆开，学习者会感到需要来回找入口。

**问题级别：P1（上下文断裂）**

### 路径 E：顶部与侧边栏的粒度不一致

顶部把“理论考试”和“技能操作”当作两个并列栏目；侧边栏却把理论十章、技能五项、设备项目卡、训练和治理页面混合组织。顶部没有“核心术语表”“综合学习课”等同级入口，用户无法从顶部判断这些页面属于哪个栏目。

**问题级别：P2（层级与命名不一致）**

## 四、最小改造建议

建议不要先改内容页，而是先统一导航模型：

### 方案 1：保留当前页面文件，调整入口指向（推荐，改动最小）

1. 把顶部“理论考试”改成一个明确的理论总览入口；若暂不新增页面，可先指向 `/training-theory`，或在 `/theory/01-professional-ethics` 前增加理论入口页。
2. 把顶部“技能操作”改名为“技能考核”或“技能路线”，指向 `/skill-roadmap`；不要直接指向“设施监控”。
3. 顶部增加“课程路线”或“学习路线”，统一指向 `/beginner-guide`；将当前“零基础导学”保留为清晰入口。
4. 顶部增加一个“训练”下拉菜单，包含训练总览、理论训练、技能训练；不要让训练只靠首页侧边栏可见。
5. 在理论和技能侧边栏顶部增加一个稳定的“学习导航”组，至少保留：首页、零基础导学、技能路线图、训练总览、术语表。这样进入深层页面后不会完全丢失上层上下文。

### 方案 2：按“课程—理论—技能—训练”重构（后续优化）

将信息架构固定为四个一级栏目：

- **开始学习**：首页、考核说明、零基础导学、术语表、来源
- **理论课程**：理论总览、十章理论
- **技能课程**：技能路线图、四项主线、三类设备项目卡
- **只读训练**：训练总览、理论训练、技能训练、题源说明

`标准逐条映射`可放到“来源/课程治理”中，不作为普通学习者的主导航入口。

## 五、建议的优先级

| 优先级 | 修正项 | 原因 |
|---|---|---|
| P0 | 顶部“技能操作”改为指向技能路线图，并修正显示名 | 直接影响当前报考方向的第一步选择 |
| P1 | 理论/技能侧边栏保留稳定的上层学习导航 | 解决进入深层页面后导航上下文消失 |
| P1 | 为理论和技能增加明确的总览入口 | 避免顶部栏目直接落到第 1 个子章节 |
| P2 | 统一顶部与侧边栏的栏目命名和粒度 | 消除“顶部是栏目、侧边栏是混合目录”的认知负担 |
| P2 | 将标准映射从普通学习菜单降级为参考/治理入口 | 减少零基础用户看到审计型页面后的干扰 |

## 六、审查边界

本轮确认的是导航配置和静态链接关系，不等于浏览器渲染后的视觉审查。未启动 VitePress 开发服务器，也未修改配置。下一步如果你确认方向，建议先按 P0/P1 做一次最小导航改造，再由用户本地打开站点确认实际视觉和点击手感。
