# 1. 设施监控

## 本章定位

本职业功能主要对应**消防设施监控操作方向**。监控不是盯着屏幕等报警，而是持续判断系统是否处于正常、可用和受控状态，并对火警、故障、监管和屏蔽信息做出不同处理。

## 一、先认识“控制器”是什么

控制器不是普通电脑屏幕，而是消防设施接收信息、显示状态、发出控制指令并保存记录的核心设备。零基础可以先把它理解成“消防系统的收发室”：现场设备把信息送进来，控制器把信息分类显示；需要联动时，控制器再把指令送给泵、风机、广播、卷帘等执行设备，并等待运行、到位或故障反馈。

### 1. 先认识四类设备角色

| 角色 | 常见设备 | 它在信号链中做什么 |
| --- | --- | --- |
| 输入设备 | 感烟/感温探测器、手动报警按钮、水流指示器、压力开关 | 把现场烟、温、人工触发或水力状态变成系统可识别的信息 |
| 控制显示设备 | 火灾报警控制器、联动控制器、图形显示装置 | 接收、分类、显示信息，按条件输出控制指令并保存记录 |
| 执行设备 | 消防泵、风机、风阀、广播、卷帘、照明等 | 接到指令后完成启动、关闭、切换或播报等动作 |
| 反馈设备/信号 | 运行触点、到位开关、故障触点、输入模块 | 把执行设备的实际状态返回控制器 |

因此，“控制器显示有输出”只说明指令链的一部分完成；还要分别确认现场是否动作、是否到位、是否有反馈。

### 2. 先认识控制器上的四类信息

| 信息 | 表示什么 | 第一反应 |
| --- | --- | --- |
| 火灾报警 | 探测器、手动按钮等报告疑似火情 | 记录位置，按预案核实、报告、组织处置 |
| 故障 | 设备、线路、电源或通信可能异常 | 查询故障对象和影响，报告维修，不当作火警也不当作正常 |
| 监管报警 | 受监管设备或输入状态异常 | 查明输入对象和现场状态，按单位程序报告 |
| 屏蔽/隔离 | 某设备或功能暂时不参与监视/联动 | 确认授权、原因、范围、临时防护和恢复要求 |

还要识别正常监视、主电/备电、手动/自动、联动启动和反馈状态。

### 3. “正常监视”到底是什么

“正常监视”不是屏幕亮着就算正常，而是系统正在按设计持续接收现场信息，且没有未处理的火警、故障、监管、屏蔽/隔离或异常手动状态。初学者可按下面顺序观察：

1. 控制器是否显示正常监视或等效状态；
2. 是否存在未处理的火警、故障、监管、屏蔽/隔离信息；
3. 主电和备用电源状态是否符合要求；
4. 相关泵、风机、阀门、卷帘等是否处于规定的自动/联动状态；
5. 是否有设备停用、手动、维修或临时防护记录未收口。

不同品牌控制器按钮名称可能不同，训练时要把页面上的通用逻辑对应到具体设备说明书。

### 4. 初学者如何读懂控制器界面

看到控制器界面时，不要只盯着颜色或声音。先按“状态—对象—时间—影响—下一步”五个问题读取：

| 要读什么 | 零基础理解 | 不能直接推出什么 |
| --- | --- | --- |
| 状态类别 | 当前是火警、故障、监管、屏蔽/隔离、启动还是正常监视 | 不能因为有一条信息就断定整套系统都异常 |
| 对象位置 | 设备类型、回路、地址、区域或分区，说明是哪一个对象发出信息 | 不能把控制室标签直接当成现场实际位置，需结合图纸/标签核对 |
| 时间和顺序 | 信息何时出现、先出现什么、后出现什么，帮助判断因果关系 | 不能用后来出现的显示覆盖最初现象 |
| 影响范围 | 单点、同回路、同分区还是多系统同时出现 | 不能只看一条故障就更换单个设备 |
| 下一步 | 核实、报告、按方案测试、维修升级或恢复记录 | 不能未经授权直接复位、屏蔽、断电或改配置 |

### 5. 消音、复位、确认和屏蔽不是一回事

- **消音**：只处理提示声响，让人员能够继续读取信息；原事件可能仍然存在。
- **确认**：表示人员已经读取并接手处理信息，通常要留下时间、对象和责任人记录；确认不等于故障排除。
- **复位**：在触发条件已经消失、现场允许恢复时，让控制器和相关设备回到规定监视状态；复位后仍应检查是否重新报警或产生故障。
- **屏蔽/隔离**：让特定设备或功能暂时不参与监视或联动，保护范围会减少，必须有授权、原因、范围、临时措施、责任人和恢复期限。

因此，看到一条信息时的正确顺序是：**先读清并记录 → 判断保护影响 → 按预案核实 → 由授权人员决定消音/复位/屏蔽 → 验证结果 → 记录恢复或遗留风险**。不能把“控制器安静了”作为“系统正常”的结论。

## 二、报警信息处理闭环

1. **看清楚**：查看液晶屏、指示灯、地址、设备类型、时间和区域；
2. **记下来**：记录报警类别、地址、时间、数量和当前控制方式；
3. **分类型**：判断是火警、故障、监管、屏蔽还是反馈信息；
4. **核实现场**：通过消防电话、对讲、现场巡查或授权人员确认；
5. **按预案处理**：火警优先保护人员、报警、疏散和报告；故障转入维修和临时防护流程；
6. **确认结果**：查看现场动作、控制器反馈和新增信息；
7. **恢复记录**：满足复位条件后复位并确认正常监视，不能恢复时保留信息、升级报告。

## 三、为什么不能先消音再说

消音只是停止或暂时停止声响提示，不等于火警或故障已经排除。可以在确认信息已经被记录、有人负责核实后按规程消音，但不能为了安静而直接复位、屏蔽或断电。

## 四、训练任务

在模拟控制器上分别练习：

- 看到火灾报警时说出地址、时间、核实方式和报告对象；
- 看到故障时指出是电源、回路、设备还是通信类信息，并说明不能做什么；
- 看到屏蔽时说出授权、原因、影响范围、临时措施和恢复责任人；
- 处置结束后逐项检查自动/手动、主/备电、联动和正常监视状态。

> 实际设备操作必须在鉴定站或有资质人员指导下进行，不可自行制造短路、断线或屏蔽故障。
