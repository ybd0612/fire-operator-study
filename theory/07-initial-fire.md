# 7. 初起火灾处置知识

## 本章学习目标

学完本章，你应该能判断“先救人还是先灭火”，知道报警、疏散、灭火器检查和现场保护的基本顺序，并能说明不同灭火剂的适用边界。

## 一、处置总原则

发现火情后，不要把“拿灭火器”当成第一反应。基本顺序是：**保护人员安全 → 立即报警和报告 → 组织疏散 → 在安全且经过培训的前提下处置初起火灾 → 火势扩大立即撤离 → 保护现场并配合调查**。

操作员的职责是按预案和授权行动，不是冒险进入浓烟、高温、缺氧或有爆炸危险区域。

## 二、灭火剂怎么选

| 灭火剂/器材 | 适合的基本场景 | 主要风险或限制 |
| --- | --- | --- |
| 水 | 一般 A 类固体火灾的冷却 | 带电、油类、遇水反应物不能直接套用 |
| 泡沫 | 某些 A/B 类火灾，依产品和泡沫类型 | 水溶性液体要使用相适配的泡沫 |
| ABC 干粉 | 常见固体、液体、气体及部分带电火灾 | 喷射后会残留粉末，设备保护和复燃要考虑 |
| BC 干粉 | 主要用于 B/C 类及适用的带电场景 | 不把它当作 A 类固体火灾的通用答案 |
| 二氧化碳 | 某些 B/C/E 类和对残留敏感的场景 | 窒息、冻伤和复燃风险；不能用于所有火灾，密闭空间必须先考虑人员安全 |
| 洁净气体系统 | 设计用于特定封闭防护区 | 释放前后人员疏散、联动、延时和防护要求很重要 |
| D 类专用灭火剂 | 适配特定金属火灾 | 必须按金属种类和产品铭牌选择，不能用普通灭火器替代 |
| F 类专用灭火器/灭火系统 | 适配烹饪器具内油脂火灾 | 依据产品认证和现场配置使用，严禁直接泼水 |

最终选择要看燃烧对象、是否带电、灭火器铭牌、现场环境和单位预案。

## 三、先区分“报警、疏散、灭火、复燃观察”四件事

初起火灾处置不是一个按钮动作，而是几项任务同时协作：

| 任务 | 目的 | 典型动作 | 易错点 |
| --- | --- | --- | --- |
| 报警/报告 | 让控制室、单位和消防救援力量获得信息 | 触发报警、拨打 119、说明地点和燃烧物 | 不能因为火小或有人处理就延迟报警 |
| 疏散/救人 | 先减少人员伤亡 | 引导人员远离烟气和危险区域，清点人员 | 不能为了取物或确认火势返回危险区 |
| 初起灭火 | 在安全条件满足时控制火势 | 选择适配器材，保持退路并按训练动作操作 | 不能把“会用灭火器”当成进入浓烟的许可 |
| 复燃观察/现场保护 | 防止再次起火并保留调查条件 | 观察、警戒、报告、保护痕迹 | 不能刚看不到火焰就清理、断电或离开 |

这四件事有先后关系，也可能并行进行。人员安全和报警优先级高于追求“马上把火扑灭”。

## 四、灭火器的检查、配置和报废边界

前面的“选择灭火剂”回答的是发生火情时怎么判断；平时还要会判断一具灭火器能不能作为可用器材。检查不是只看压力表，而是沿着“位置—类型—外观—部件—标识—记录”逐项核对：

| 检查项 | 小白要看什么 | 发现异常意味着什么 |
| --- | --- | --- |
| 位置和可达性 | 是否在规定位置、无遮挡、标识清楚、取用路线通畅 | 即使器材本体完好，取不到也不能认为配置有效 |
| 类型和铭牌 | 灭火剂、适用火灾类别、使用方法和警示 | 类型不匹配时不能临时拿来“试一下” |
| 瓶体和软管 | 是否锈蚀、变形、泄漏、破损或喷嘴堵塞 | 可能影响承压、喷射和人员安全，应隔离并按制度送检/维修 |
| 保险装置和铅封 | 保险销、铅封是否完整，是否有被使用痕迹 | 被使用过或封签异常，不能仅凭外观继续当作满状态器材 |
| 压力或状态指示 | 仅在该型号具有相应指示装置时，按铭牌和说明观察 | 指示异常不能自行充装或拆压，应交由授权单位处理 |
| 维修、检验和报废信息 | 日期、编号、状态标签是否清楚且未超出适用要求 | 不能凭“看起来新”推断仍在有效状态 |

检查发现异常时，先记录编号、位置和缺陷，设置替代器材或临时防护并报告责任人；不要自行拆卸、泄压、充装或修改标签。具体维修周期、检验和报废判定必须以产品标识、现行标准、单位制度和有资质机构结论为准，本站不写死一个脱离型号和版本的统一年限。

## 五、灭火器检查和使用

### 先判断“烧的是什么”和“是否带电”

灭火器不是看到火就随便拿一具。零基础先按两个问题判断：**正在燃烧的对象是什么？设备或线路是否可能带电？**

| 看到的对象 | 先理解成什么 | 选择和安全边界 |
| --- | --- | --- |
| 木材、纸张、棉织物等普通固体 | 主要是 A 类对象 | 关注冷却和复燃；灭火器类型按现场配置和铭牌确认 |
| 汽油、酒精等液体或可熔化固体 | 主要是 B 类对象 | 防止液体飞溅和火势扩散，不用水柱盲目冲击液面 |
| 天然气、液化气等气体 | 主要是 C 类对象 | 重点是报警、人员安全和在安全条件下切断气源，不能只对着火焰喷射后离开 |
| 带电设备、线路 | 主要是 E 类对象 | 先按预案和授权断电，灭火剂必须适配带电风险，不湿手操作、不盲目靠近 |
| 油锅等烹饪油脂 | 主要是 F 类对象 | 不能泼水，防止高温油液飞溅扩大 |
| 镁、钠等金属 | 主要是 D 类对象 | 必须使用适配金属火灾的专用灭火剂，普通灭火器不能替代 |

这个表用于建立判断顺序，不替代灭火器铭牌、单位预案和现场指挥。出现浓烟、高温、火势扩大、退路不清或无法判断燃烧物时，应立即撤离、报警并等待专业处置，不把“会使用灭火器”理解成可以冒险进入现场。

### 使用前检查

确认灭火器类型适用，查看外观、铅封/保险销、喷管或喷嘴、压力指示（若该型号具备）、标识、维修和报废状态。发现泄漏、严重锈蚀、部件缺失或状态异常，不要把它当作有效器材使用。

### 基本使用动作

在安全前提下站在上风或侧上风方向，保持撤退路线：

1. 提起灭火器，确认火灾类别和退路；
2. 拔出保险销；
3. 握住喷管/喷嘴，对准火焰根部；
4. 压下压把，左右扫射并逐步推进；
5. 观察是否复燃，发现火势扩大立即撤离。

这是训练口诀，不是允许无条件进入火场的授权。推车式灭火器、洁净气体系统和特殊灭火设备必须按产品说明书和专业培训操作。

## 六、报警和疏散

拨打 119 时说明起火地点、起火物质、火势情况、人员被困情况以及报警人联系方式，并按现场预案触发建筑火灾报警、通知相关人员和组织疏散。人员疏散应沿安全出口和疏散指示进行，不乘普通电梯，不返回取物；烟气较大时优先远离烟气、关闭防火门并沿安全疏散路径撤离。湿毛巾只能提供有限的短时辅助，不能过滤一氧化碳等有毒气体，也不能替代防烟楼梯、呼吸防护和专业救援。

如果出口被烟火封堵，应关闭门并利用通信、呼喊、灯光等方式发出求救信号，等待救援，不盲目穿越浓烟。

## 七、场景练习

**油锅起火**：先关闭热源，在安全情况下使用适合的灭火器材或覆盖方式；直接泼水可能使高温油飞溅并扩大火势。

**配电箱冒烟**：先报警、保持距离并按授权断电；灭火器和断电方式要符合带电火灾处置要求，不能用水直接喷射带电设备。

## 八、火灾处置中的几个判断点

### 1. 什么时候可以尝试使用灭火器

同时满足以下条件，才考虑在安全范围内使用适配器材：火势仍属初起、人员已报警或正在报警、灭火器适用、操作者受过训练、退路保持畅通、没有浓烟高温或爆炸危险。任何一个条件不满足，都应优先撤离、警戒并等待专业救援。

### 2. 为什么不能把“火灭了”当成处置结束

还要观察是否复燃，保护现场，清点人员，保持消防设施和疏散条件可用，并按制度报告。涉及电气、油类、气体、可燃金属或密闭空间时，表面火焰消失不代表内部或周边危险已经消除。

### 3. 现场保护记什么

至少记录发现时间、地点、燃烧对象、报警和疏散情况、使用的器材、人员伤亡或被困信息、现场变化和移交对象。非经授权不要翻动、清理、冲洗或拆除可能影响原因调查的物品。
