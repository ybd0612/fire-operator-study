# 水系统设备项目卡

> **定位**：检测维修保养方向的可学习课程，覆盖自动喷水灭火与消防给水。本文用于建立识别、操作、保养、检测和故障闭环，不替代现行标准、设计文件、设备说明书、单位规程或鉴定站评分表。

## 1. 学习目标与安全边界

学完本卡，应能：

- 按“水源—储水—加压—控制—管网—出水—试水排水—反馈”说明水系统链路；
- 区分湿式、干式、预作用、雨淋系统的基本工作逻辑；
- 识别泵组、报警阀组、阀门、喷头、试水装置及信号部件；
- 按方案记录输入、显示、动作、反馈、恢复五项结果；
- 对异常先记录、隔离、报告和采取临时防护，不越权拆修。

::: warning 安全边界
未经授权不得关闭消防给水阀门、切断泵组电源、拆卸喷头或报警阀部件、修改压力设定和联动逻辑。涉及停用、放水、误启动或保护范围变化时，须审批、告知、监护、设置临时防护并完成复核。
:::

## 2. 系统总览

```text
消防水源
  ↓
消防水池/高位消防水箱（按设计储水）
  ↓
主泵/备用泵 ── 稳压泵及稳压设施
  ↓
报警阀组/控制阀（分区控制）
  ↓
配水干管、支管、信号阀、水流指示器
  ↓
闭式或开式喷头 / 室内消火栓
  ↓
末端试水、报警阀试水、排水设施
  ↓
压力开关、水流信号、泵运行/故障反馈 → 消防控制室
```

实际分区、共用水源、泵组配置和控制逻辑必须以竣工图、设计文件和设备资料为准，不能从示意图推导工程结论。

## 3. 设备识别卡

| 设备 | 主要用途 | 学习时确认 |
| --- | --- | --- |
| 消防水池/水箱 | 提供设计消防用水 | 水位、补水、溢流、进出水和标识 |
| 主泵/备用泵 | 提供灭火所需加压供水 | 泵号、吸水/出水阀、控制柜、运行和故障反馈 |
| 稳压泵/稳压设施 | 维持管网规定压力 | 自动状态、压力显示、频繁启停现象 |
| 报警阀组 | 分区控制并输出水流报警 | 阀体、试水/排水、警铃、压力开关及阀门状态 |
| 信号阀/控制阀 | 控制或监视管网通断 | 常开、锁定/铅封、状态反馈和标识 |
| 水流指示器 | 指示分区管网水流 | 分区、方向、信号线、动作和复位 |
| 压力开关 | 以压力变化输出信号 | 接线、设定由谁维护、启泵/报警反馈 |
| 水力警铃/延迟器 | 现场声响报警、减少短时水流误报 | 试警铃、排水、堵塞和渗漏 |
| 末端试水装置 | 模拟末端放水检查水流和信号 | 压力、排水、显示、报警、反馈和复归 |
| 喷头 | 按系统类型出水灭火 | 类型、完好、遮挡、污染、改造和动作后处理 |
| 消火栓/接合器 | 室内灭火取水、消防车供水 | 栓箱、水带水枪、阀门、接口、标识和通道 |

## 4. 四类自动喷水系统对比

::: warning 2019版考试范围边界
在《消防设施操作员国家职业技能标准（2019年版）》检测维修保养方向的 5.2 分项中，正式明列的是**湿式、干式自动喷水灭火系统**。预作用、雨淋放在本节仅用于建立系统认知，不能当作该版本中级检测维修保养方向的独立技能考点；是否涉及，以当前适用的考核大纲和报考批次要求为准。
:::

| 类型 | 基本状态与动作逻辑 | 适用理解与边界 |
| --- | --- | --- |
| 湿式 | 管网通常充有有压水，闭式喷头动作后出水并触发水流报警 | 适用于设计允许的环境；低温、腐蚀、高温等限制须看设计，不能泛化 |
| 干式 | 管网通常充有有压气体，喷头动作后先排气，再由供水进入管网 | 适用于有冻结风险等设计场景；排气和充水会带来动作延迟 |
| 预作用 | 由预作用控制逻辑控制充水，喷头与控制条件按设计配合 | 用于降低误喷或特殊保护风险；不得把某一种预作用逻辑套用于所有工程 |
| 雨淋 | 采用开式喷头，满足启动条件后保护区集中喷水 | 用于特定危险场所或区域；启动可能造成较大范围放水，试验须严格审批 |

> 本节是理论扩展。系统分类、组件配置、启动条件、保护等级和性能判定属于设计及现行标准项目，考试或现场结论不得仅凭表格作出。

## 5. 水流与报警信号链

```text
末端试水/喷头放水
  → 管网水流变化
  → 水流指示器（分区信号）/报警阀组
  → 压力开关、水力警铃、延迟器（按系统配置）
  → 输入模块/消防控制器显示
  → 泵启动、运行/故障反馈（按设计逻辑）
```

水流指示器主要帮助定位分区水流；压力开关可参与报警或启泵信号；报警阀组承担分区控制和水流报警功能；水力警铃是现场声响提示；延迟器用于特定系统中延缓短时水压波动造成的误报警。各信号的具体接线和联动关系应查图纸、说明书和方案。

## 6. 现场状态与停用管理

每次操作、保养或检测前后至少核对：阀门常开及锁定状态、水池/水箱水位、泵组和控制柜供电、泵房压力显示、自动/手动状态、排水路径、防冻措施、通道和环境。放水前确认排水能力、地面防滑和电气防护；低温区域关注管网、阀组和水源冻结风险。

::: warning 停用闭环
停用前确认影响区域和时限 → 审批并告知相关岗位 → 设置临时防护和巡查 → 记录停用阀门/设备 → 完成作业 → 恢复阀门、供电、自动/联动状态 → 现场与控制室双重确认并报告。
:::

## 7. 泵组启停与主备切换操作卡

1. 确认任务、区域、授权、供水条件、排水和人员安全；
2. 核对主泵/备用泵/稳压泵、控制方式、供电、吸水和出水阀状态；
3. 按设备说明书选择就地/远程、手动/自动方式并执行启动；
4. 观察泵运行、压力变化、异常声音/振动、控制柜指示、运行/故障反馈和控制室显示；
5. 按方案进行主备切换时，记录切换对象、触发条件和结果，不自行制造故障；
6. 停泵仅在授权和任务允许时进行，随后恢复自动/联动并记录。

> 电机转动、控制柜亮灯或压力表有读数，都不能单独证明供水功能合格；判定还需按方案核对阀门、水源、压力/流量测量、反馈和恢复。

## 8. 末端试水与报警阀试验卡

> 末端试水主要用于检验测试点的启动、报警和联动过程，并记录该测试点的压力、流量等结果；不能用单个末端试水点的数据推算整个系统的供水能力、最不利点性能或全系统合格性。

- 查方案确定测试点、预期信号、允许放水方式和恢复要求；
- 通知控制室及受影响岗位，确认排水、防误启动和监护措施；
- 缓慢开启试水装置或按方案进行报警阀试验，观察水流、压力、警铃、控制器显示、压力开关、水流指示器和泵组反馈；
- 记录实际测量值及仪器信息，不能凭记忆填写统一压力、流量或持续时间；
- 按方案关闭试水/试验阀，确认无渗漏，恢复控制阀、控制柜自动/联动和控制室正常监视。

## 9. 保养卡

按“外观—连接—状态—功能—记录”执行：清洁并检查泵、阀组、管道、喷头、箱体和标识；查看渗漏、锈蚀、压力、水位、供电、阀门锁定和环境；按授权计划验证功能。不得以外观整洁替代功能检测，不得擅自调整设定、拆卸喷头、堵塞排水或改变阀门状态。

## 10. 检测五项结果

| 结果 | 水系统记录示例 |
| --- | --- |
| 输入/触发 | 末端试水、报警阀试水、模拟信号或方案指定触发 |
| 显示 | 控制器显示的区域、设备、类别和时间 |
| 动作 | 水流、警铃、泵组、阀门或喷头相关动作 |
| 反馈 | 水流指示器、压力开关、泵运行/故障和控制室信号 |
| 恢复 | 试水阀、控制阀、控制柜自动/联动、排水和监视状态 |

判定依据必须写明标准/版本、设计文件、设备说明书或检测方案；量值、允许误差和动作时间不使用未经核对的统一阈值。施工验收或调试条款中的时间、压力、声级等数值，只能在对应条款适用场景下引用，不能直接改写成日常保养通用阈值。

## 11. 故障树：先现象，后原因

| 现象 | 优先排查方向（仅为授权排查框架） |
| --- | --- |
| 泵启动无压/压力异常 | 水位、吸水条件、阀门、旋向/机械、仪表、管网泄漏和反馈；禁止只看电机 |
| 稳压泵频繁启停 | 渗漏、压力波动、气压/稳压部件、设定和控制回路；设定调整交专业人员 |
| 末端无水 | 控制阀、分区、管网堵塞/冻结、水源和排水条件 |
| 水流指示器不动作 | 水流方向、浆片/机构、分区接线、模块和复位状态 |
| 压力开关不动作 | 压力变化、取压/接线、模块、设定和设备故障 |
| 报警阀不报警 | 阀组状态、试水/排水、警铃通路、延迟器、压力和信号回路 |
| 管道/阀组漏水 | 密封、连接、腐蚀、冻结损伤和异常压力；先隔离并报告 |
| 阀门误关 | 核对标识、锁定和监视，评估保护范围，启动停用与临时防护流程 |
| 冻结 | 环境、防冻措施、受冻部位和系统损伤；不得未经评估强行操作 |
| 动作但无反馈 | 现场动作、模块/线路、控制器输入和供电分别验证 |

## 12. 维修边界与停用恢复

维修遵循“现象记录—判断—安全隔离—授权处理—功能验证—恢复记录”。普通操作员可报告、观察和按方案复核；涉及电气拆装、报警阀内部、泵体、压力设定、管网改造、喷头更换或联动逻辑的工作，由具备相应授权的专业人员执行。维修后须验证原故障消失、无新增故障、输入/显示/动作/反馈完整，并恢复规定阀门、供电、自动/联动/监视状态。

## 14. 原创训练场景题

> 以下均为原创训练题，不是官方评分表或历年真题。

### S-W01 · 泵启动但无压力

**场景**：泵电机运行，压力未按预期变化。  
**标准判断**：不得宣布合格或继续盲目运行；记录现象，核对水位、吸水/出水阀、管网、仪表和反馈，按授权隔离、报告并复核。

### S-W02 · 末端试水无报警

**场景**：末端有放水，但控制室未显示预期信号。  
**标准判断**：记录试水点和时间，核对水流指示器、压力开关、模块、线路、控制器显示及排水，不得直接填写“系统正常”。

### S-W03 · 报警阀组试验无警铃

**场景**：试验有水流，现场水力警铃不响。  
**标准判断**：停止扩大试验，按方案核对警铃通路、试警铃阀、延迟器/过滤部件和渗漏，报告维修人员；测试后恢复并记录。

### S-W04 · 主备泵切换

**场景**：按计划验证主泵与备用泵切换。  
**标准判断**：先核对授权、供电、阀门和预期触发条件；分别记录运行、压力、控制柜和控制室反馈，禁止拔线或人为制造故障，完成自动状态复归。

### S-W05 · 发现分区控制阀误关

**场景**：巡检发现信号阀未处于规定常开状态。  
**标准判断**：评估影响区域，立即报告并按单位流程设置临时防护；不得无授权强行开启或仅在记录上写“已恢复”，须由责任人员确认。

### S-W06 · 测试后遗留手动状态

**场景**：试水结束，设备停止，但控制柜仍手动且控制器有故障。  
**标准判断**：不能宣布完成；核实故障和保护影响，按权限恢复自动/联动，报告并记录复核结果。

## 15. 依据与版本边界

学习依据包括《消防设施操作员国家职业技能标准（2019年版）》、现行建筑消防给水及自动喷水灭火系统相关国家标准、地方鉴定站实施要求、项目设计文件、竣工资料和设备说明书。标准可能修订，页面不固化水箱容积、压力、流量、持续时间或动作时间等统一数值；使用时必须核对现行版本和现场方案。理论扩展用于理解系统，不得替代设计审查、检测报告或有资质人员的工程判断。
