# 4. 设施维修

检测维修保养方向涉及设施维修。中级工以常见故障判断、简单更换和维修后的功能确认能力为重点；涉及系统改造、参数变更和复杂板卡维修时，应由专业维修人员执行。

## 一、故障诊断思路

1. 读取控制器故障信息，记录地址、时间和现象。
2. 结合图纸、回路和现场位置确认对象。
3. 先查电源、接线、端子、线路通断、松动、污染和环境因素，再判断部件故障。
4. 按规程更换同型号或经批准的部件，做好停用、隔离和防误动作措施。
5. 维修后进行功能测试、复位、恢复自动/联动，确认无新增故障并填写记录。

## 二、常见故障方向

- **探测器故障**：污染、进水、损坏、底座接触不良、地址或线路异常。
- **手报/模块故障**：按钮损坏、端子松动、线路断路/短路、模块反馈异常。
- **主备电故障**：市电中断、保险/开关异常、蓄电池欠压、接线不良。
- **通信/回路故障**：线路开路、短路、接地、屏蔽或回路设备异常。
- **水泵/风机不启动**：控制方式错误、电源缺失、保护动作、阀门/机械异常或反馈线路故障。

## 三、安全边界

- 未断电、未验电、未隔离时不得拆装电气部件。
- 不得用短接、拔线、屏蔽等方式“消除”故障提示。
- 不得随意改地址、改联动逻辑、改保护参数或替换非匹配器件。
- 维修影响消防保护时，必须报告、告知并落实临时防护措施。

## 四、评分要点

故障定位有依据、操作前有安全确认、工具和部件匹配、拆装顺序正确、测试项目完整、系统状态恢复正确、记录清楚。不能仅说“换一个试试”，要说明现象—判断—处理—验证的闭环。
