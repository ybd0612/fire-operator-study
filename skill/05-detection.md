# 5. 设施检测

## 本章定位

设施检测主要对应检测维修保养方向。检测不是“按一下设备看它动不动”，而是依据标准、方案和设备说明书，对输入、控制、动作、反馈、供电和恢复进行有记录的验证。

## 一、检测前准备

1. 明确检测对象、区域、系统范围和检测目的；
2. 查阅现行标准、检测方案、图纸、设备说明书和历史记录；
3. 通知消防控制室、相关岗位和可能受影响人员；
4. 评估误启动消防泵、风机、卷帘、广播或气体灭火的风险；
5. 准备警示、隔离、监护、复位和恢复措施；
6. 核对仪器量程、精度、校准/检定状态、电池和接线。

## 二、检测的五个结果

每个项目至少记录：

- **输入/触发**：什么探测器、按钮、试水或信号被触发；
- **显示**：控制器显示了什么地址、类别和时间；
- **动作**：风机、泵、广播、卷帘或其他设备是否动作；
- **反馈**：控制器是否收到设备到位、运行或故障反馈；
- **恢复**：复位后是否回到规定状态，有无新增故障。

只记录“设备动作了”是不完整的检测结论。

## 三、按系统理解检测

### 火灾自动报警系统

检查探测器、手动报警按钮、声光警报器、输入/输出模块、控制器显示、打印/记录、主备电和联动反馈。测试时要防止触发真实联动造成设备误动作。

### 消防联动控制

按方案验证报警信号与泵、风机、风阀、广播、电话、卷帘和电梯迫降等对象之间的逻辑关系。每次测试都要明确触发条件、预期动作和反馈位置。

### 水系统

根据方案检查泵组启停、主备切换、末端试水、报警阀组、水流指示器、压力开关和控制器信号。压力、流量、持续时间等阈值不能凭记忆填写，必须引用检测依据。

### 防烟排烟系统

检查风机、风阀、排烟口/送风口动作、控制器显示、反馈和恢复。现场人员必须远离运动部件并落实误启动防护。

## 四、检测记录示例

| 项目 | 应记录内容 |
| --- | --- |
| 对象 | 设备名称、编号、位置 |
| 方法 | 触发方式、仪器、接线和方案 |
| 结果 | 显示、动作、反馈、测量值 |
| 判定依据 | 标准/版本、设备说明书、检测方案 |
| 异常 | 未动作、无反馈、误报警、参数异常 |
| 后续 | 临时措施、维修建议、报告和复测 |

## 五、自测

1. 检测和日常保养有什么区别？
2. 为什么“有动作”不能直接等于“合格”？
3. 检测前为什么必须通知相关岗位？
4. 哪些数值必须查标准和检测方案？

> 参考：[《消防设施操作员国家职业技能标准（2019年版）》](https://xfhyjd.119.gov.cn/)；检测阈值、允许误差和动作时间必须以现行国家标准、地方鉴定站实施细则、设备说明书和检测方案为准。现场检测必须由经过培训和授权的人员实施。
