# 4. 设施维修

## 本章定位

设施维修主要对应检测维修保养方向的常见故障判断、部件更换和维修后确认。零基础先学“如何定位问题”，再学“如何处理”，不能从拆装开始。

## 一、故障闭环：现象—判断—处理—验证

### 1. 记录现象

记录控制器显示、地址、时间、声音、指示灯、现场状态和故障是否重复出现。不要只写“设备坏了”。

### 2. 建立可能原因

按电源、接线、通信/回路、部件、环境和机械部分分类排查。先检查简单、可见、风险低的原因，再按规程进入更深入检查。

### 3. 安全隔离

确认停用范围、影响对象、临时防护、审批和监护。电气部件要断电、验电并防止误送电；不能靠拔线或短接让故障提示消失。

### 4. 处理和更换

只有在授权、工具和部件匹配的前提下，按设备说明书和维修规程处理。复杂板卡维修、系统改造、联动逻辑和保护参数变更由专业人员执行。

### 5. 功能验证

维修后要检查原故障是否消失、是否产生新增故障，按需要进行报警、反馈、联动和恢复测试，并确认自动/联动/监视状态。

### 6. 记录报告

记录原因判断依据、处理动作、替换部件、测试结果、遗留风险、报告对象和复核人员。

## 二、维修前的故障分层

先判断故障属于哪一层，再决定由谁处理：

| 层级 | 典型现象 | 首要问题 | 处理边界 |
| --- | --- | --- | --- |
| 信息层 | 显示地址、类别、时间不一致 | 记录是否完整，显示链路是否可信 | 不删记录、不用重启掩盖问题 |
| 供电层 | 主电/备电故障、设备掉线 | 电源范围、切换和影响对象是什么 | 电气检查须授权、断电、验电和隔离 |
| 线路/通信层 | 成片设备异常、回路或通信故障 | 是局部设备还是线路/接口共同问题 | 不短接、不盲目拔线，由授权人员测试 |
| 现场设备层 | 探测器、模块、泵、风机不动作 | 设备本体、机械状态和控制条件是否满足 | 按说明书和维修规程处理 |
| 逻辑/配置层 | 输出条件不满足、反馈点不对应 | 设计逻辑、地址映射和配置是否一致 | 不擅自改地址、逻辑或保护参数 |

> 分层的作用是避免“看到一个故障就直接换部件”。先找共同原因，再进入设备级处理，能减少误拆和保护缺口。

## 三、常见故障如何思考

- 探测器故障：看污染、进水、底座接触、地址、线路和环境；
- 手报/模块故障：看端子、线路、模块输入输出和反馈；
- 主备电故障：看供电、开关、保险、蓄电池和接线；
- 回路/通信故障：看开路、短路、接地、屏蔽和设备异常；
- 泵/风机不启动：看控制方式、电源、保护动作、阀门/机械状态和反馈线路。

这些是排查方向，不是允许在现场无授权拆装的操作清单。

## 四、典型故障诊断卡

### 1. 探测器无报或反复报警

- **先记录**：地址、时间、报警/故障类别、同区域其他设备状态和现场环境；
- **再分层**：单点异常优先核对探测器、底座、污染和环境；成片异常优先核对回路、供电或通信；
- **安全处理**：需要拆装、清洁或更换时按授权隔离并落实临时防护；
- **验证**：按适配方法复测输入、显示、警报、联动/反馈和恢复；
- **报告**：写明原始现象、原因依据、处理动作、复测结果和遗留风险。

### 2. 回路或通信故障

- **先判断范围**：看同一回路、分区或通信链路是否同时出现异常；
- **核对可见项**：检查供电、端子、设备状态、环境和近期施工影响；
- **禁止越权**：不得短接、随意拔线或修改地址来恢复“正常”显示；
- **验证恢复**：由授权人员按方案进行线路/通信测试，确认设备上线、无新增故障并恢复监视。

### 3. 主备电故障

- **先确认影响**：记录主电、备用电源、控制器状态和受影响设备；
- **安全隔离**：电气维修执行断电、验电、隔离和防误送电；
- **处理原则**：按设备说明书检查开关、保险、接线和蓄电池，匹配更换部件；
- **复测重点**：确认供电、切换、控制器显示和记录恢复，不以“控制器亮屏”单独判定合格。

### 4. 水泵不启动或启动无反馈

- **先核对条件**：控制方式、任务触发、供电、阀门、水源和保护装置；
- **再看现场**：控制柜、泵组运行、压力变化、异常声音/振动和反馈线路；
- **处理边界**：不得擅自改变压力设定、关闭阀门或人为制造故障；
- **复测记录**：按方案确认启动、运行/故障反馈、压力或其他测量结果和自动状态恢复。

### 5. 风机、风阀或卷帘动作异常

- **先确认安全**：运动部件区域无人、无障碍，落实误启动防护；
- **区分现象**：未收到输出、收到输出未动作、动作但无反馈，排查路径不同；
- **按层定位**：控制方式、输出模块、电源、执行机构、限位/反馈和机械障碍分别核对；
- **结束复核**：按方案恢复自动/联动/监视，不能把“电机转动”或“卷帘移动”直接写成系统合格。

## 五、案例：控制器提示某探测器故障

错误做法：直接复位；复位后仍提示就拔掉探测器；最后填写“已处理”。

正确闭环：记录地址和时间 → 查看同回路其他设备是否异常 → 核对现场安装、污染和接线 → 按授权隔离和维修 → 更换匹配部件或交专业人员 → 功能测试 → 确认无新增故障 → 恢复系统并记录。
