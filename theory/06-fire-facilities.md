# 6. 消防设施基础知识

本模块是理论 + 技能操作的枢纽，建议与「技能操作考核」配合学习。

## 一、火灾自动报警系统（FAS）

- **作用**：早期探测火灾、发出声光警报、联动控制其他消防设施。
- **组成**：
  - 触发器件：感烟 / 感温探测器、火焰探测器、手动火灾报警按钮。
  - 警报装置：声光警报器、警铃。
  - 控制装置：**火灾报警控制器**、**消防联动控制器**、消防控制室图形显示装置。
  - 通信：消防电话、消防应急广播。
- **工作原理**：探测器感知烟 / 温 → 报警控制器接收并显示报警部位 → 确认后联动声光警报、应急广播、防排烟、消防泵、防火卷帘等。
- **常见探测器**：
  - 点型感烟（光电式为主）、点型感温（定温 / 差温）。
  - 线型：缆式感温、红外光束感烟。
  - 火焰探测器（红外 / 紫外），用于油类等场所。

## 二、自动灭火系统

### 1. 自动喷水灭火系统（最常用）

| 系统 | 准工作状态管道 | 适用环境 | 特点 |
| --- | --- | --- | --- |
| **湿式** | 充满有压水 | 4–70℃ | 响应快，最常用 |
| **干式** | 充满有压气体 | 寒冷（<4℃） | 喷头动作后先排气再充水 |
| **预作用** | 不充水 | 怕误喷 / 寒冷 | 报警后充水，双重确认 |
| **雨淋** | 开式喷头 | 严重危险 | 报警后大面积喷水 |
| **水幕** | — | 分隔 / 冷却 | 阻火、冷却 |

- **关键组件**：喷头、报警阀组（**湿式报警阀 + 延迟器 + 压力开关 + 水力警铃**）、水流指示器、末端试水装置（检测系统末端的压力与流量）。

### 2. 其他灭火系统

- **水喷雾**：灭火 / 防护冷却。
- **细水雾**：高效冷却 + 窒息。
- **气体灭火系统**：适用于机房、配电室等忌水场所。常见 **CO₂、IG541（惰性气体）、七氟丙烷（HFC-227ea）**；分有管网与预制（无管网）。
- **泡沫灭火系统**：非水溶性 / 水溶性液体（B 类）火灾。
- **干粉灭火系统**：可燃液体、气体、电气火灾。

## 三、其他消防设施

- **消火栓系统**：室外消火栓、室内消火栓（水枪 + 水带 + 栓阀）、消防水泵接合器。
- **防烟排烟系统**：
  - 防烟：正压送风（楼梯间 / 前室加压，阻止烟气进入）。
  - 排烟：机械排烟（排烟风机、排烟口、排烟防火阀）、自然排烟（可开启外窗）；并设补风。
- **防火分隔设施**：防火墙、防火门、防火卷帘、防火窗、防火阀等。防火门耐火等级、阀门动作温度及构造要求必须以现行产品标准、设计/验收标准和题干条件为准；本站不把“甲/乙/丙固定小时数、70 ℃/280 ℃”脱离标准版本写成所有场景的通用答案。
- **应急照明和疏散指示系统**：火灾时点亮疏散路径（集中电源 / 自带电源）。
- **消防供配电**：消防电源、消防设备末端配电装置（主电 / 备电**自动切换**）。
- **消防电梯**：火灾时供消防员使用，联动迫降首层。

## 四、零基础易错点

- 湿式充水（常温）、干式充气（寒冷）——**环境区分**是常考。
- 报警阀组四件套：**湿式报警阀、延迟器、压力开关、水力警铃**，缺一不可。
- 防火门等级、阀门动作温度要先看题干所依据的现行标准和具体设施，不要把旧题库口诀当作无条件通用答案。
- 气体灭火用于**忌水场所**（机房、配电室）。

## 五、学习建议

本模块是后续技能操作（报警控制器、消防泵、防排烟、防火卷帘）的理论底座，先看原理、再练操作，事半功倍。
