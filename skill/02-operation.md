# 2. 设施操作

## 本章定位

设施操作是两个中级职业方向共同的职业功能。学习目标不是记住“按哪个按钮”，而是能说明操作对象、控制方式、安全条件、动作结果、反馈信号和恢复状态。

## 一、统一操作框架

### 1. 确认任务和对象

读清设备名称、区域、任务目的和要求。确认操作的是消防泵、风机、广播、卷帘还是控制器功能，避免选错区域或误操作相邻设备。

### 2. 确认安全条件

确认人员已避开运动部件和危险区域，联动影响已告知，控制方式和授权正确，必要的隔离、监护和警示已经落实。

### 3. 选择控制方式

区分就地/远程、手动/自动、主泵/备泵、主电/备电等状态。控制方式不同，设备是否会联动、反馈是否出现也可能不同。

### 4. 执行并观察

按设备说明书和鉴定站评分表操作，同时观察控制器显示、现场动作、指示灯、压力/风阀位置、声光效果和反馈信号。

### 5. 恢复并记录

按任务要求停止、复位、恢复自动/联动/监视状态，确认无新增故障，填写记录并报告异常。

## 二、先理解“控制方式”为什么会改变结果

| 控制方式 | 零基础理解 | 可能带来的差异 |
| --- | --- | --- |
| 就地控制 | 在设备附近通过本地按钮、柜体或机构操作 | 需要确认现场人员、运动部件和本地状态 |
| 远程控制 | 在控制室或远端控制设备 | 需要确认通信、权限、联动条件和现场反馈 |
| 手动控制 | 由人员发出明确操作指令 | 不代表设备一定动作，还要观察执行和反馈 |
| 自动控制 | 满足设计逻辑和条件后系统自动输出 | 不能擅自假设所有输入都会触发同一联动 |
| 主泵/备用泵 | 主设备和备用设备按设计承担供水任务 | 供电、优先级、切换和反馈可能不同 |

控制器“显示手动”不是故障本身，但意味着不能直接假设系统会自动联动；恢复结束时要把控制方式作为独立结果记录。

### 每张操作卡都要写清三类结果

- **预期结果**：按方案执行后，控制器、现场设备和反馈分别应出现什么；
- **异常分支**：没有输出、输出未动作、动作无反馈、动作后未恢复分别怎么记录和升级；
- **结束条件**：自动/联动/监视、阀门、供电、现场安全和记录是否恢复。

## 二、火灾报警和联动控制

零基础先认识三类对象：输入设备（探测器、按钮、压力开关等）、控制设备（报警/联动控制器）、输出设备（泵、风机、广播、卷帘等）。训练时每次都回答：输入是什么？控制器显示什么？输出设备动作什么？反馈从哪里回来？

常见训练内容包括火警/故障查询、消音、复位、手动/自动识别、联动控制盘操作和状态恢复。具体按钮、密码、菜单和权限必须按现场设备说明书执行。

## 三、设备级操作卡

下面不是固定品牌的按钮教程，而是进入任何实操题前都要能说清的“对象—条件—动作—反馈—恢复”卡。菜单名称、密码、端子和按钮位置必须以现场设备说明书和鉴定站评分表为准。

### 1. 火灾自动报警系统操作卡

| 环节 | 学习要点 |
| --- | --- |
| 对象识别 | 区分探测器、手动火灾报警按钮、输入模块、输出模块、报警控制器、联动控制器和火灾警报装置。 |
| 操作前 | 核对区域、任务、授权、控制方式、当前火警/故障/屏蔽状态，确认不会误启动现场设备。 |
| 执行动作 | 按方案触发或操作目标功能；涉及联动输出时，先确认人员、设备和动作区域安全。 |
| 结果观察 | 同时看控制器显示、现场声光/执行机构动作、运行状态和反馈信号；“输出已发出”不等于“现场已动作”。 |
| 恢复记录 | 按要求消音、复位或恢复自动/联动/监视，确认无新增故障，记录原始状态、动作、反馈和异常。 |

**典型判断：**控制器显示火警时，不能因为现场暂未发现明火就直接复位；应先按预案核实、报告并判断处置。控制器显示故障时，不能用拔线、屏蔽或断电代替故障处理。

### 2. 消防给水和自动灭火系统操作卡

| 环节 | 学习要点 |
| --- | --- |
| 对象识别 | 区分水源、水池/水箱、消防泵、稳压泵、控制柜、报警阀组、控制阀、水流指示器、压力开关和末端试水装置。 |
| 操作前 | 核对测试区域、供水范围、阀门状态、电源、控制方式、排水条件和人员安全；放水或启泵必须有授权。 |
| 执行动作 | 按任务选择就地/远程、手动/自动或规定测试方式，观察启动、运行和压力变化，不擅自关闭保护阀门。 |
| 结果观察 | 核对泵组运行、控制柜指示、管网压力、水流/压力信号、控制器显示和现场有无渗漏。 |
| 恢复记录 | 按方案停止或恢复自动，关闭试水装置并确认排水、阀门、控制柜和监视状态，记录测试点和异常。 |

**边界：**泵电机转动只说明出现运行现象，不能单独证明供水能力合格；末端有水也不能推算全系统性能。湿式、干式、预作用、雨淋等系统的具体操作必须先确认现场系统形式和依据。

### 3. 其他消防设施操作卡

| 对象 | 操作前 | 必须核对的结果 |
| --- | --- | --- |
| 防烟排烟 | 确认人员疏散影响、风机/风阀区域和授权 | 风机动作、风阀位置、控制器反馈、故障状态 |
| 防火门/卷帘/防火阀 | 清空运动区域，确认无人、无障碍和限位风险 | 启停/升降、到位、限位、现场安全和反馈 |
| 应急照明/疏散指示 | 确认测试范围和供电方式，不遮挡疏散路径 | 灯具状态、集中电源/控制器状态、故障信息 |
| 消防广播/电话 | 核对目标分区、话筒或分机、内容和音量 | 目标区域可听、通话接通清晰、控制室状态和恢复 |
| 消防电梯迫降 | 仅按预案、授权和现场条件执行 | 迫降信号、相关反馈、设备状态和恢复条件 |

**共同结束条件：**动作已停止不等于任务完成。必须确认规定的自动、联动、监视或常态状态已恢复；不能恢复时要保留异常、报告并落实临时防护。

## 三、消防泵组

### 设备认知

识别消防水泵、稳压泵、控制柜、压力表、阀门、水泵接合器、启泵按钮和反馈模块。

### 操作时观察什么

- 启动前：电源、控制方式、阀门、管网和区域安全；
- 启动中：泵是否运行、压力变化、异常声音/振动、控制柜指示；
- 启动后：主备泵、压力开关、控制器反馈和现场状态；
- 结束时：停泵权限、阀门状态、自动状态和记录。

不要在没有确认的情况下切断电源或关闭阀门，也不要把泵电机转动当作供水功能已经合格。

## 四、防烟排烟

识别送风机、排烟风机、风阀、排烟口、送风口和控制柜。操作后同时确认风机动作、风阀开闭、控制器反馈和现场气流/状态。防排烟系统涉及人员疏散，不能为演示随意改变系统运行状态。

## 五、应急广播和消防电话

广播操作要确认目标分区、话筒/音量、广播内容和目标区域是否听清；消防电话操作要确认分机、主机接通和通话清晰。普通背景广播和消防应急广播不能混淆。

## 六、防火卷帘和电梯迫降

卷帘操作前清空下方区域并确认授权，操作后核对上升/下降/停止、限位和反馈。电梯迫降必须按预案和授权执行，确认相关信号和状态，不把迫降当成无条件的日常试验。

## 七、训练记录

每次练习记录：任务、设备、操作前状态、控制方式、动作结果、反馈结果、恢复状态、异常和指导人员。记录的目的不是应付形式，而是帮助你发现“动作了但没反馈”“复位了但未恢复自动”等问题。

## 八、自测

1. 为什么操作前必须确认手动/自动状态？
2. 启动消防泵后要看哪些反馈？
3. 风机动作了，为什么还要检查风阀和反馈？
4. 防火卷帘操作前最重要的现场安全确认是什么？
