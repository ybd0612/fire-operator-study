# 消防设施操作员（四级 / 中级工）检测维修保养学习站

这是一个面向个人学习的消防设施操作员考试学习站，主要服务于以下目标：

> **参加消防设施操作员四级 / 中级工考试，报考方向为“消防设施检测维修保养”。**

站点按照“先理解基础，再认识系统，最后训练操作、保养、维修和检测闭环”的思路组织内容，适合零基础学习者逐章阅读、复习和建立知识体系。

## 部署到 GitHub Pages

1. 将本目录内容推送至 GitHub 仓库；
2. 在仓库 **Settings → Pages → Build and deployment → Source** 中选择 **GitHub Actions**；
3. 推送 `main` 分支后，由工作流自动构建和发布。

当前项目使用自定义域名 `fire.yangbang.de`，因此 `.vitepress/config.js` 中使用根路径：

```js
base: '/'
```

如果将项目改为 GitHub Pages 项目页，而不是自定义域名或用户页，需要根据实际访问路径重新设置 `base`。
